# 문서 쓰기

Kari의 문서는 워드프로세서처럼 글이 흐르고 쪽이 나뉘는 문서다. 저장 단추는 없다. 고칠 때마다 저장되고, 화면 위쪽에 "자동 저장됨 · 시각"이 보인다.

## 문서 목록 (홈)

| 하려는 것 | 하는 법 |
|---|---|
| 새 문서 | 홈의 "새 문서" |
| 이름 바꾸기, 복제, 휴지통으로 옮기기 | 문서 줄의 더 보기 메뉴 |
| 되살리기, 완전히 삭제 | 홈의 "휴지통 N개" → 문서마다 "되살리기", "완전히 삭제" |

완전히 삭제한 문서는 되돌릴 수 없다. 홈의 나머지(면접 카드, 준비 줄)는 [interview.md](interview.md#홈)에 있다.

## 화면

| 자리 | 있는 것 |
|---|---|
| 위쪽 줄 | 문서 이름, 저장 상태, 되돌리기, 다시 하기, `PDF로 내보내기`, `⋯` 메뉴(`인쇄…`, `공유…`, `Word 문서로 내보내기…`, `텍스트로 내보내기…`, `쪽 설정`, `버전 기록`, `개요`, `표 눈금선 보기`) |
| 도구 줄 | 문단 스타일, 글자 크기, 굵게·기울임·밑줄, 글자색, 정렬, 글머리표·번호, 내어쓰기·들여쓰기, `넣기`, `서식`. 그림을 고르면 `그림 크기`가 더 나온다. 창이 좁으면 정렬 넷은 펼침 하나로 접힌다 |
| 표 도구 줄 | 커서가 표 안에 있을 때 나온다: `행`, `열`, `합치기`, `되나누기`, `선`, `바탕색`, 세로 맞춤, `표 속성…`, `표 지우기` |
| 개요 패널 | 켜면 종이 왼쪽에 나온다. 창이 좁으면 종이 위에 겹쳐 뜨고, 바깥을 누르면 닫힌다 |
| 상태 줄 | 쪽 수, 글자 수, 공백 제외 글자 수, 낱말 수(공백과 줄바꿈으로 나눈 덩어리. 선택이 있으면 선택 안의 수도), 보기 배율 단추 |

| 메뉴 | 항목 |
|---|---|
| 문단 스타일 | 스타일 목록, `선택에 맞게 "…" 고치기`, `"…" 고치기…`, `새 스타일…`, `이 문서의 스타일을 새 문서의 기본으로` |
| `넣기` | 표, 이미지, 링크, 탭 정지, 가로줄 |
| `서식` | 취소선, 형광펜, 위 첨자, 아래 첨자, `글자 모양…`, `문단 모양…`, 줄 간격 1·1.15·1.5·2, 쪽 나누기, 서식 지우기. 번호 목록 안에서는 `번호 시작 값…` |

### 메뉴 막대

macOS 메뉴 막대의 항목은 도구 줄과 단축키와 같은 일을 한다. 편집 화면이 아니거나 대화 상자가 떠 있으면 문서 항목은 꺼진다.

| 메뉴 | 항목 |
|---|---|
| Kari | `설정…`과 macOS가 주는 항목(정보, 서비스, 가리기, 끝내기) |
| 파일 | `새 문서`, `홈으로`, `PDF로 내보내기…`, `인쇄…`, `공유…`, `쪽 설정…`, `버전 기록` |
| 편집 | 되돌리기, 다시 하기, 잘라내기, 복사, 붙여넣기, `서식 없이 붙여넣기`, 모두 선택, `찾기…`, `찾아 바꾸기…`, `다음 찾기`, `이전 찾기`, `쪽으로 가기…` |
| 보기 | 확대, 축소, 실제 크기, 쪽 너비에 맞춤, 개요, 표 눈금선, 전체 화면 |
| 넣기 | `표…`, `이미지…`, `링크…`, `탭 정지…`, 쪽 나누기, `오늘 날짜`(`YYYY-MM-DD`, `YYYY. M. D.`, `YYYY년 M월 D일`) |
| 서식 | 굵게, 기울임, 밑줄, 취소선, 위 첨자, 아래 첨자, 글자 크게, 글자 작게, `대소문자`, `글자 모양…`, `문단 모양…`, 정렬, 줄 간격, 글머리표, 번호, `번호 시작 값…`, 들여쓰기, 내어쓰기, 서식 지우기 |
| 창, 도움말 | macOS가 주는 항목 |

## 글자 모양

| 기능 | 내용 |
|---|---|
| 글자 크기 | 도구 줄의 크기 칸에 1~400pt(소수 한 자리)를 치고 Enter, 또는 펼쳐서 8~72pt의 16단계에서 고른다. ⇧⌘>, ⇧⌘<는 이 단계표의 다음, 앞 크기로 간다 |
| 굵게, 기울임, 밑줄, 취소선 | 도구 줄의 단추와 `서식`의 취소선. 켜진 것은 눌린 모양이다 |
| 글자색 | 도구 줄의 글자색 단추: 견본 20개, 색 값(`#` 뒤 16진수 여섯 자리), `스타일 색으로`(직접 준 색을 걷고 문단 스타일의 색으로) |
| 형광펜 | `서식` → 형광펜: 견본 8개, `형광펜 없음` |
| 위 첨자, 아래 첨자 | ⌘., ⌘, 또는 `서식`. 누를 때마다 켜고 끈다. 글자를 작게 줄여 기준선 위, 아래에 놓고 줄 높이는 그대로 둔다 |
| 자간 | `글자 모양…`의 자간. −2~10pt |
| `글자 모양…` 창 | 크기, 자간, 글자색, 형광펜(비우면 없음), 첨자(없음, 위 첨자, 아래 첨자) |
| 서식 지우기 | ⌘\ 또는 `서식` → `서식 지우기`. 직접 준 글자 모양을 걷어 문단 스타일의 모양으로 돌린다. 링크는 남는다. 문단 전체를 골랐으면 직접 준 문단 모양도 걷는다(목록과 탭 정지는 남는다) |
| 대소문자 | 메뉴 막대의 `서식` → `대소문자`: 모두 대문자, 모두 소문자, 단어 첫 글자만. 고른 글의 라틴 문자만 바꾼다 |

- 고른 글이 없으면 다음에 칠 글자에 적용된다.
- 두 창(`글자 모양…`, `문단 모양…`)에서 고른 범위 안의 값이 섞인 칸은 비어 있고, 고친 칸만 바뀐다. 범위를 벗어난 값이 있으면 적용하지 않고 알린다.

## 문단 모양

| 기능 | 내용 |
|---|---|
| 문단 스타일 | 도구 줄 맨 앞의 스타일 메뉴. 기본 스타일은 본문, 제목, 부제, 제목 1~6. ⌘⌥0은 본문, ⌘⌥1~6은 제목 1~6 |
| 정렬 | 왼쪽, 가운데, 오른쪽, 양쪽. ⇧⌘L, ⇧⌘E, ⇧⌘R, ⇧⌘J |
| 줄 간격 | `서식`의 1, 1.15, 1.5, 2(배). 1배는 글자 크기의 1.2배다 |
| `문단 모양…` 창 | 들여쓰기 왼쪽·오른쪽(cm), 첫 줄(없음, 첫 줄, 내어쓰기)과 그 값(cm), 문단 앞·뒤 간격(0~200pt), 줄 간격(배수 0.5~5 또는 고정 1~200pt), 쪽과 줄(`다음 문단과 함께`, `문단을 나누지 않기`, `문단 앞에서 쪽 나누기`), 테두리와 바탕 |
| 테두리와 바탕 | `문단 모양…` 창이나 스타일 고치기 창에서. 위·아래·왼쪽·오른쪽 변을 켜고 끈다(`상자`는 넷 다, `없음`은 다 끔). 굵기(0.25~6pt), 선 색, 글과의 거리(0~31pt), 바탕색(비우면 없음). 바로 이웃한 문단의 테두리와 바탕이 같으면 한 상자로 이어진다 |
| 가로줄 | `넣기` → `가로줄`. 커서 문단 바로 뒤에 아래 선만 있는 빈 문단을 넣는다 |
| 쪽 나누기 | ⌘Enter 또는 `서식` → `쪽 나누기`. 커서 자리에서 문단을 나누고 뒤 문단을 다음 쪽 처음에 놓는다. 표 안에서는 메뉴 항목이 꺼진다. 나뉜 문단의 맨 앞에서 ⌫를 누르면 쪽 나누기부터 없어진다 |
| 목록 | 글머리표(`•` `◦` `▪`), 번호(`1.` `가.` `1)` `가)` `(1)` `(가)` `①` `㉮`). 수준은 Tab, ⇧Tab. 번호 목록에서 `서식` → `번호 시작 값…`(1~9999)으로 커서 문단부터 그 값으로 다시 센다 |
| 탭 정지 | `넣기` → `탭 정지`. 위치(mm), 맞춤(왼쪽, 가운데, 오른쪽, 소수점), 채움선(없음, 점, 대시, 선). "오른쪽 끝 맞춤 탭"으로 본문 오른쪽 끝에 맞춘 정지를 더한다. 정지가 없으면 36pt(12.7mm)마다 왼쪽 맞춤으로 간다 |
| 링크 | ⌘K 또는 `넣기` → `링크`. 보일 글과 주소(`https://…` 또는 메일 주소). 주소에 스킴이 없으면 메일 주소는 `mailto:`, 그 밖에는 `https://`를 붙인다. ⌘를 누른 채 링크를 누르면 기본 브라우저로 연다 |

- `다음 문단과 함께`가 켜진 문단은 다음 문단의 첫 줄과 같은 쪽에 놓인다. `제목 1`~`제목 6`은 기본으로 켜져 있어 쪽 아래에 제목만 남지 않는다.
- `문단을 나누지 않기`가 켜진 문단은 한 쪽에 들어가는 길이일 때 지금 쪽에 다 들어가지 않으면 다음 쪽에서 시작한다.
- 문단의 첫 줄이나 마지막 줄 하나만 다른 쪽에 떨어지지 않는다.

## 스타일

스타일 메뉴는 스타일 이름을 그 스타일의 굵기로, 크기에 비례한 크기로 보인다. 지금 문단에 직접 준 모양이 있으면 그 스타일 줄에 점이 찍힌다.

| 하려는 것 | 하는 법 |
|---|---|
| 선택에 맞게 고치기 | `선택에 맞게 "…" 고치기`. 선택의 첫 문단에 직접 준 모양을 스타일에 넣고, 그 문단의 직접 모양은 걷는다 |
| 고치기 | `"…" 고치기…`: 이름, 바탕 스타일, 다음 문단의 스타일, 글자(크기, 글자색, 자간, 굵게·기울임·밑줄·취소선), 문단(정렬, 줄 간격, 들여쓰기, 문단 앞·뒤 간격, 쪽과 줄), 테두리와 바탕. 옅은 값은 바탕 스타일에서 온 것이고, 칸을 비우면 바탕 스타일을 따른다 |
| 새 스타일 | `새 스타일…`: 이름과 바탕(지금 문단의 모양 또는 스타일 하나). 지금 문단의 모양으로 만들면 그 문단에 바로 쓴다 |
| 지우기 | 직접 만든 스타일의 고치기 창에서 `지우기`. 그 스타일을 쓰던 문단은 그 스타일의 바탕 스타일(없으면 본문)로 바뀐다 |
| 기본값으로 | 기본 스타일의 고치기 창에서 `기본값으로` |
| 새 문서의 기본 | `이 문서의 스타일을 새 문서의 기본으로`. 설정 → 문서 → `새 문서의 스타일`에서 `앱 기본값`과 `저장한 값` 가운데 고르고, `앱 기본값으로 되돌리기`로 저장한 값을 지운다 |

- 스타일 이름은 1~40자이고 문서 안에서 겹치지 않는다. 스타일은 문서마다 100개까지다.

## 표

| 기능 | 내용 |
|---|---|
| 넣기 | `넣기` → `표`. 행 1~50, 열 1~20. 커서 문단 뒤에 넣고, 열 폭은 본문 폭을 같게 나눈다 |
| 칸 고르기 | 여러 칸에 걸쳐 고르면 그 칸들의 사각 범위가 고른 칸이 된다. 아래의 선, 바탕색, 세로 맞춤, `표 속성…`의 칸 값은 고른 칸(없으면 커서 칸)에 적용된다 |
| 행, 열 | `행`: 위에 넣기, 아래에 넣기, 행 지우기. `열`: 왼쪽에 넣기, 오른쪽에 넣기, 열 지우기 |
| 합치기, 되나누기 | 여러 칸을 고른 뒤 `합치기`. 합친 칸에서 `되나누기` |
| 선 | `모든 선`, `바깥 선`, `안쪽 선`, `안쪽 가로`, `안쪽 세로`, `한 변`(위, 아래, 왼쪽, 오른쪽), `선 없음`, `기본 선으로`(표의 기본 선을 따름). 메뉴 아래에서 고른 굵기(0.25~3pt의 7단계)와 선 색(견본 20개)을 쓰고, 앱을 끌 때까지 기억한다 |
| 바탕색 | 견본(형광펜 8개, 글자색 20개), 색 값(`#` 뒤 16진수 여섯 자리), `없음` |
| 세로 맞춤 | 위, 중간, 아래 |
| `표 속성…` | 표: 맞춤(왼쪽, 가운데, 오른쪽), 기본 선 굵기(0~6pt)와 색, 머리 행 수. 열과 행: 고른 열의 폭(cm), `열 폭 같게`, 고른 행의 최소 높이(cm, 0은 내용에 맞춤), `행 높이 같게`. 칸: 안쪽 여백 위·오른쪽·아래·왼쪽(cm), 세로 맞춤. 빈칸은 고른 칸들에서 값이 섞인 것이고, 고친 값만 되돌리기 한 단위로 바꾼다 |
| 열 폭 같게, 행 높이 같게 | 고른 열의 폭을 그 평균으로, 고른 행의 최소 높이를 그 가운데 가장 큰 높이로 맞춘다. 한 열(행)만 골랐으면 표의 모든 열(행) |
| 경계 끌기 | 표의 경계에 포인터를 대면 크기 바꾸기 모양이 된다. 끌어 놓으면 열 폭이나 행 높이가 바뀐다. 열 경계는 양옆 두 열만 바꿔 표 폭이 그대로이고, 맨 오른쪽 경계는 마지막 열만 바꾼다(본문 폭까지). 열은 12pt보다 좁아지지 않고, 행은 내용보다 낮아지지 않는다 |
| 표 눈금선 | `⋯` → `표 눈금선 보기`, 또는 메뉴 막대의 `보기` → `표 눈금선`. 선이 없는 변을 옅은 점선으로 화면에만 보인다. PDF와 인쇄에는 나오지 않는다. 처음에는 켜져 있고, 모든 문서에 같이 쓰인다 |
| 머리 행 | 표가 쪽을 넘어가면 넘어간 쪽마다 맨 위에 다시 그린다 |
| 셀 사이 이동 | Tab은 다음 셀, ⇧Tab은 이전 셀. 마지막 셀에서 Tab을 누르면 아래에 행을 넣는다 |
| 복사와 붙여넣기 | 표 전체나 칸 범위를 복사해 Kari 안의 본문에 붙이면 새 표가 된다. 칸 범위를 표 안에 붙이면 커서 칸(칸을 골랐으면 그 범위의 왼쪽 위)부터 칸의 내용을 덮어쓰고, 표가 모자라면 들어가는 만큼 붙인다. 다른 앱으로는 행은 줄, 칸은 탭으로 나뉜 글이 나간다 |

표 안에는 표를 넣거나 붙일 수 없다. 행은 쪽에서 나뉘지 않고 통째로 다음 쪽으로 간다.

## 그림

| 기능 | 내용 |
|---|---|
| 넣기 | `넣기` → `이미지` → PNG나 JPEG 파일 고르기. 20MB까지 |
| 정리 | 사진의 방향 정보대로 똑바로 돌린다. 긴 변이 4,000px를 넘으면 줄여 넣는다 |
| 크기, 대체 글 | 그림이 선택되면 도구 줄의 "그림 크기". 폭을 mm나 본문 폭의 %로 정한다. 비율은 그대로이고 본문 폭과 높이를 넘지 못한다. 대체 글은 그림을 볼 수 없을 때 읽어 줄 설명 |

## 쪽 설정

`⋯` 메뉴의 `쪽 설정`에서 고친다.

| 항목 | 값 |
|---|---|
| 용지 | A4, A5, B5, Letter, 사용자 지정(너비와 높이 cm, 한 변 1.76~70.56cm. 방향은 두 변으로 정해진다) |
| 방향 | 세로, 가로 |
| 여백 | 위, 아래, 왼쪽, 오른쪽(mm). 보통(20mm), 좁게(12.7mm), 넓게(25.4mm). 본문이 가로·세로 25.4mm 이상 남아야 한다 |
| 머리글, 바닥글 | 각각 왼쪽, 가운데, 오른쪽 칸. `{쪽}`은 그 쪽의 번호, `{전체}`는 전체 쪽 수로 바뀐다 |
| 쪽 번호 넣기 | 바닥글 가운데에 `{쪽} / {전체}`를 넣는다 |
| 첫 쪽에는 넣지 않기 | 첫 쪽에 머리글과 바닥글을 넣지 않는다 |

## 보기 배율

- 상태 줄의 배율 단추에서 50, 75, 90, 100, 125, 150, 200, 300%와 `쪽 너비에 맞춤`을 고른다.
- ⌘+, ⌘−는 이 단계로 한 단계씩, ⌘0은 100%. 트랙패드를 벌리거나 오므리면 50~300% 사이에서 1% 단위로 바뀐다.
- 배율을 바꿔도 화면 가운데에 보던 곳이 그 자리에 남는다. 쪽이 창보다 넓으면 가로로 스크롤한다.
- 배율은 모든 문서에 같이 쓰이고, 앱을 다시 열어도 남는다. 배치와 PDF는 배율과 상관없이 같다.

## 개요와 쪽으로 가기

- 개요: ⌥⌘O, `⋯` → `개요`, 또는 메뉴 막대의 `보기` → `개요`. 제목 스타일(제목, 부제, 제목 1~6)을 쓴 문단을 단계대로 들여 보이고, 줄마다 쪽 번호가 붙는다. 누르면 그 제목으로 간다. 커서가 속한 제목은 강조색 바탕이다. 켜고 끈 것은 앱을 다시 열어도 남는다.
- 쪽으로 가기: ⌥⌘G 또는 `편집` → `쪽으로 가기…`. 쪽 번호를 넣으면 그 쪽의 첫 줄로 간다. 마지막 쪽보다 큰 수면 마지막 쪽으로 간다.

## 입력하면서 자동 서식

| 친 것 | 바뀌는 것 |
|---|---|
| 문단 맨 앞에서 `-` 또는 `*` 뒤에 공백 | 글머리표 목록 |
| 문단 맨 앞에서 `1.` 또는 `1)` 뒤에 공백(1~9999) | 번호 목록. 친 수부터 센다 |
| 문단 맨 앞에서 `#`, `##`, `###` 뒤에 공백 | 제목 1, 제목 2, 제목 3 |
| 주소 뒤에 공백이나 Enter | `http://`, `https://`, `www.`로 시작하는 주소와 전자우편 주소가 링크가 된다 |

- 바로 ⌘Z를 누르면 자동 서식만 되돌아가고 친 글은 남는다.
- 이미 목록인 문단의 목록 표시, 이미 제목인 문단의 제목 표시는 그대로 둔다.
- 끄는 곳: 설정 → 문서 → `입력하면서 자동 서식`.

## 찾기와 바꾸기

- ⌘F로 찾기 막대를 연다. 고른 글이 한 문단 안에서 200자 이하면 찾을 글로 채운다. ⌥⌘F는 바꾸기까지 펼친 막대를 연다.
- 막대에는 "대소문자 구분", "단어 단위로 찾기", "바꾸기", "모두 바꾸기"가 있다. 단어 단위로 찾으면 앞뒤가 글자나 숫자인 일치는 뺀다. 키는 아래 단축키 표에 있다.
- 표의 셀 안 글도 찾는다.

## 되돌리기와 버전

- ⌘Z 되돌리기, ⇧⌘Z 다시 하기. 이어서 친 글은 한 번에 되돌아간다.
- `⋯` 메뉴의 `버전 기록`에서 버전 목록을 본다. 버전을 고르면 그때의 글을 볼 수 있다.

| 버전 | 남는 때 |
|---|---|
| 자동 | 5분 동안 고치지 않았을 때, 문서를 닫을 때, 버전으로 되돌리기 직전("되돌리기 전") |
| 이름 붙인 버전 | "지금 상태에 이름 붙이기"(200자까지) |

- "이 버전으로 되돌리기"를 하면 지금 상태는 "되돌리기 전" 버전으로 남는다. ⌘Z로도 되돌릴 수 있다.
- 버전마다 "이름 바꾸기", "지우기"가 있다.

## PDF로 내보내기

위쪽 줄의 `PDF로 내보내기` → 저장할 곳 고르기. 화면에서 본 배치 그대로 나온다. 링크는 눌리고, 글자는 고르고 찾을 수 있다. 문서 이름이 PDF의 제목이 된다.

## Word 문서와 텍스트로 내보내기

`⋯` → `Word 문서로 내보내기…` 또는 `텍스트로 내보내기…` → 저장할 곳 고르기.

- Word 문서(`.docx`)에는 글자·문단 모양, 스타일, 목록, 탭 정지, 링크, 그림, 표(열 폭, 합친 칸, 선, 바탕, 안쪽 여백, 세로 맞춤, 머리 행), 쪽 설정, 머리글·바닥글과 쪽 번호가 들어간다. 줄과 쪽은 여는 프로그램이 다시 나눈다.
- 옮기지 못했거나 비슷하게만 옮긴 것(읽지 못한 그림, 열 수 없는 주소의 링크, 반투명 색 등)은 내보낸 뒤 알린다.
- 글꼴은 담지 않는다. 받는 기기에 Pretendard가 없으면 다른 글꼴로 보인다.
- 텍스트(`.txt`, UTF-8)는 문단마다 한 줄이고, 목록 표지는 글로, 표는 행마다 한 줄(칸은 탭)로 쓴다. 그림은 빠진다.

## 인쇄와 공유

- ⌘P 또는 `⋯` → `인쇄…`: 문서를 PDF로 만들어 macOS 인쇄 창에 넘긴다. 배율 없이 실제 크기로 인쇄한다. 용지와 방향은 문서의 첫 쪽에 맞춰 두고, 인쇄 창에서 바꾸면 그 설정을 따른다.
- `⋯` → `공유…`: 문서 이름으로 된 PDF를 macOS 공유 메뉴에 넘긴다.
- 글꼴에 없는 글자가 있으면 창을 열기 전에 그 수를 알린다.
- 넘길 PDF는 앱의 임시 폴더에 만들고, 인쇄 창이 닫히거나 공유가 끝나면 지운다. 남은 것은 앱을 켤 때 지운다.

## 글꼴

문서는 앱에 든 Pretendard(보통, 굵게)로 쓴다. 이 글꼴에 없는 글자(한자, 이모지 등)는 빈 네모로 보이고, 상태 줄에 "글꼴에 없는 글자 N자(네모로 보임)"로 수를 알린다. PDF와 인쇄에도 같은 네모로 나온다.

## 복사와 붙여넣기

- ⌘C, ⌘X, ⌘V. 다른 앱으로는 글만 나간다.
- Kari 안에서 복사해 붙이면 글자 모양, 링크, 그림, 문단 모양, 표가 함께 간다. 다른 문서에 붙이면 문단이 쓰는 스타일도 함께 가고, 같은 이름의 스타일이 있으면 그것을 쓴다.
- ⇧⌘V(서식 없이 붙여넣기)는 글만 붙인다.
