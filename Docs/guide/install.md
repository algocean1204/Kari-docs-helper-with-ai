# Kari 설치와 처음 여는 법

Kari(카리)는 이력서를 쓰고, 그 이력서와 채용공고로 기술 면접을 글로 연습하는 맥 앱이다.


## 1. 필요한 기기

- Apple Silicon 맥(M1, M2, M3, M4 등)
- macOS 13(Ventura) 이상
- 내 맥의 칩과 macOS 판은 화면 왼쪽 위의 사과 메뉴 → "이 Mac에 관하여"에서 볼 수 있다.


## 2. 설치

1. 받은 `.dmg` 파일을 두 번 누른다. 창이 하나 열린다.
2. 창 안의 `Kari`를 옆의 `Applications`(응용 프로그램) 폴더 위로 끌어다 놓는다.
3. 창을 닫고, Finder 옆 막대의 디스크(Kari) 옆 꺼내기 단추를 누른다.


## 3. 처음 여는 법

이 판은 Apple 공증 없이 배포된다. 그래서 처음 열 때 macOS가 앱을 막고, 한 번 허락하면 그다음부터는 그냥 열린다.
방법은 macOS 판에 따라 다르다.

macOS 15(Sequoia) 이상
1. 응용 프로그램 폴더에서 Kari를 두 번 눌러 연다. 경고 창이 뜨면 "완료"를 누른다(휴지통으로 옮기지 않는다).
2. 사과 메뉴 → 시스템 설정 → 개인정보 보호 및 보안으로 간다.
3. 아래로 내려 "보안" 부분에서 Kari 옆의 "그래도 열기"를 누른다.
4. 맥의 암호(또는 Touch ID)를 넣고, 다시 뜨는 창에서 "그래도 열기"를 누른다.
5. "그래도 열기" 단추는 막힌 뒤 한 시간쯤만 보인다. 안 보이면 1번부터 다시 한다.

macOS 13(Ventura), 14(Sonoma)
1. 응용 프로그램 폴더에서 Kari를 Control 키를 누른 채 누른다(또는 오른쪽 단추로 누른다).
2. 나온 메뉴에서 "열기"를 누른다.
3. 경고 창에서 다시 "열기"를 누른다.
4. 열리지 않으면 위의 "macOS 15 이상" 방법(시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기)을 쓴다.

터미널을 쓸 수 있으면 Kari를 응용 프로그램 폴더로 옮긴 뒤 아래 한 줄로도 된다. 내려받은 파일에 붙는 격리 표시를 지운다. 이 저장소의 릴리스에서 받은 파일에만 쓴다.

```bash
xattr -dr com.apple.quarantine /Applications/Kari.app
```


### 업데이트

- 앱 안에서 업데이트할 수 있는 판이면 "설정" → "업데이트"에 지금 쓰는 판과 빌드 번호, `지금 확인` 단추(메뉴의 `업데이트 확인…`과 같다), `자동으로 업데이트 확인` 스위치가 있다(스위치는 처음에는 켜져 있다). 그렇지 않은 판이면 그 자리에 "이 판은 앱 안에서 업데이트할 수 없습니다"가 적혀 있다. 소스에서 만든 빌드처럼 빌드 번호가 숫자가 아닌 빌드는 앱 안 업데이트를 끄고 그 자리에 그렇다고 적는다. 그때는 GitHub의 Releases에서 새 dmg를 받아 2절처럼 설치한다.
- 스위치가 켜져 있으면 Kari가 24시간에 한 번까지 GitHub의 Kari 릴리스에 새 판이 있는지 묻는다. 메뉴 막대의 `Kari` → `업데이트 확인…`으로 바로 물을 수도 있다.
- 새 판이 있으면 "새 판이 있습니다" 창에 판, 빌드 번호, 바뀐 점이 보인다. 바뀐 점의 제목, 목록, 굵은 글, 링크는 서식대로 보이고 링크를 누르면 기본 브라우저로 연다.
  - `지금 업데이트`: 새 판을 받아 설치한다. 설치하려면 Kari가 닫힌다. Kari가 닫히지 않았으면 화면 아래에 "Kari를 끄면 업데이트가 설치됩니다"와 `다시 시도`가 보인다.
  - `나중에`: 아무것도 받지 않는다.
- `지금 업데이트`를 누르지 않으면 받거나 설치하지 않는다. 받은 새 판은 Kari의 릴리스 서명이 맞을 때만 설치한다.
- 받거나 설치하지 못하면 화면 아래에 알린다.
- 업데이트 확인이 무엇을 보내는지는 [privacy.md](privacy.md)에 있다.


## 4. 할 수 있는 것

- 문서 만들기, 이름 바꾸기, 복제, 휴지통
- 캔버스: 대지 위에 도형, 글 상자, 그림을 자유롭게 놓는 문서([canvas.md](canvas.md))
- 글쓰기와 한글 입력
- 글자 모양(크기, 굵게·기울임·밑줄·취소선, 글자색, 형광펜, 위·아래 첨자, 자간, 대소문자, 서식 지우기)과 문단 모양(정렬, 들여쓰기, 문단 간격, 줄 간격, 쪽 나누기, 테두리와 바탕)
- 스타일(고치기, 새 스타일, 새 문서의 기본 스타일)
- 입력하면서 자동 서식(목록, 제목, 주소를 링크로)
- 목록(번호 시작 값), 탭 정지, 링크, 가로줄, 오늘 날짜
- 표(칸마다 선과 바탕, 표 속성, 경계를 끌어 열 폭·행 높이 바꾸기, 셀 합치기, 쪽이 넘어가면 머리 행 반복, 표와 칸 복사·붙여넣기)
- 그림(PNG, JPEG)
- 찾기·바꾸기(낱말 단위), 글자 수와 낱말 수, 개요, 쪽으로 가기
- 쪽 설정(용지 크기와 방향, 사용자 지정 용지, 여백), 머리글·바닥글, 쪽 번호
- 되돌리기·다시 하기, 자동 저장, 버전(예전 상태로 돌아가기)
- PDF로 내보내기(링크가 눌리고 글자를 고르고 찾을 수 있는 PDF), Word 문서(DOCX)와 텍스트로 내보내기
- 다른 앱의 파일 가져오기: Word 문서(DOCX), HTML, Google Docs의 웹 페이지 꾸러미(zip)를 새 글 문서로([writing.md](writing.md#가져오기))
- 인쇄, 공유, 보기 배율(50~300%, 쪽 너비에 맞춤), macOS 메뉴 막대
- 채용공고 붙여넣기
- 글로 하는 면접 연습과 리포트(백엔드 개발 직무)
- 홈에서 이력서의 주장 가운데 면접에서 방어한 수와 먼저 준비할 주장 보기
- 시선 기록: 면접 중에 화면을 보고 있는지만 본다(카메라를 쓴다. 준비 화면과 설정에서 끌 수 있다)

저장 단추는 없다. 고칠 때마다 저장된다. 자세한 쓰는 법은 [writing.md](writing.md)와 [interview.md](interview.md)에 있다.


## 5. AI 키 넣기와 비용 (면접 연습에만 필요)

문서 쓰기와 PDF 내보내기는 키 없이 된다. 면접 연습에는 본인의 Anthropic(Claude) 또는 OpenAI API 키가 필요하다. 둘 중 하나만 있어도 된다.

1. 쓸 제공사의 개발자 콘솔(Anthropic은 https://console.anthropic.com, OpenAI는 https://platform.openai.com)에서 가입하고 결제 수단을 등록한 뒤 API 키를 만든다.
2. Kari의 옆 메뉴에서 "설정" → "AI 연결"의 그 제공사 줄(Claude 또는 OpenAI)에서 "키 넣기"를 누르고, 키를 붙여넣은 뒤 "확인하고 저장"을 누른다.
3. 키는 제공사마다 따로 넣고 지운다. 키는 이 맥의 키체인에만 둔다.
4. 키를 저장하면 그 자리에 다음 걸음 `면접 연습으로`가 보인다. 채용공고를 아직 넣지 않았으면 `공고 추가`도 함께 보인다.

### OpenAI 키 대신 ChatGPT 플랜 쓰기

OpenAI는 API 키 대신 내 ChatGPT 플랜의 사용량으로도 쓸 수 있다. OpenAI의 공식 "Sign in with ChatGPT"(오픈 소스·로컬 앱용)를 쓴다.

1. "설정" → "AI 연결"의 OpenAI 줄 아래 `ChatGPT 플랜` 줄에서 `ChatGPT로 계속하기`를 누른다.
2. 기본 브라우저에 ChatGPT 로그인 창이 열린다. 앱의 줄에는 `브라우저에서 로그인을 마치세요`와 `취소`가 보인다. 처음이면 브라우저에서 앱 이름(Kari)과 요청하는 권한을 보고 허락한다.
3. 마치면 브라우저에 "ChatGPT 로그인을 마쳤습니다"가 보이고, 앱에는 처음 한 번만 `ChatGPT 플랜을 씁니다` 안내가 뜬다. 줄에는 `ChatGPT 플랜 사용 · <계정 전자우편>`(전자우편을 받지 못하면 `ChatGPT 플랜 사용`)과 `연결 끊기`가 보인다.
4. 10분 안에 마치지 않거나 `취소`를 누르면 아무것도 연결하지 않는다. 허락하지 않았으면 줄에 그 까닭이 보이고, 다시 `ChatGPT로 계속하기`를 누르면 허락을 다시 묻는다.

- OpenAI API 키와 ChatGPT 플랜이 둘 다 있으면 ChatGPT 플랜을 먼저 쓴다. 줄 아래의 `API 키로 바꾸기`(또는 `ChatGPT 플랜으로 바꾸기`)로 바꾼다.
- ChatGPT 플랜으로 보낸 연습은 API 요금이 아니므로 리포트의 "이번 연습"에 `추정 비용 알 수 없음`으로 보인다.
- 사용량과 이 앱의 한도는 ChatGPT 설정의 사용량(https://chatgpt.com/settings/usage)에서 본다. "면접에 쓰는 모델"과 모델 창에 `ChatGPT 플랜 사용`과 `사용량 관리`가 보인다.
- 면접 중 한도에 닿으면 `사용량 관리`가 먼저 보이고, OpenAI API 키가 있으면 `API 키로 계속`으로 키로 바꿔 같은 답을 다시 보낸다.
- `연결 끊기`는 ChatGPT 서버에서 이 로그인을 끝내고 이 기기의 로그인 정보를 지운다. 서버에서 끝낸 것을 확인하지 못하면 그렇게 알리고, 이때는 ChatGPT 설정에서 이 앱의 연결을 끊을 수 있다.

키를 만드는 곳과 비용이 든다는 것은 앱의 "설정" → "AI 연결"과 키 넣기 창에도 적혀 있다. 키 넣기 창의 눈 모양 단추로 붙여넣은 키를 보이거나 다시 가린다. 창을 닫으면 다시 가려진다.

키 넣기 창은 단계마다 상태를 보여 준다.
- 입력: 칸 위에 `Claude API 키`(또는 `OpenAI API 키`)라는 이름이 있고, 칸에는 `sk-ant-`(OpenAI는 `sk-`)로 시작한다는 안내가 있다. `붙여넣기` 단추는 클립보드의 글을 칸에 넣는다.
- 쓰는 동안: 네트워크를 쓰지 않고 글자만 보고 알린다. 키가 짧으면 `확인하고 저장`이 꺼져 있고, 꼴이 맞으면 `꼴이 맞습니다`가 보인다. 다른 제공사의 키 같으면 `OpenAI 키처럼 보입니다`(또는 `Claude 키처럼 보입니다`)라고 경고하지만 확인은 막지 않는다.
- 확인 중: 칸 안에 `확인 중…`이 보이고 칸과 단추가 잠긴다.
- 성공: 칸의 테두리가 초록색이 되고 `확인됨 · 저장됨`이 잠깐 보인 뒤 창이 닫힌다.
- 실패: 칸의 테두리가 빨간색이 되고 까닭(키가 올바르지 않음, 권한 없음, 네트워크 연결 실패, 요청이 몰림 등)이 한 줄로 보인다. `다시 시도`를 누르면 같은 키를 다시 확인한다.

"설정" 화면에는 위에서부터 이런 묶음이 있다.
- `AI 연결`: Claude와 OpenAI 두 줄과 OpenAI 아래의 `ChatGPT 플랜` 줄(위의 "OpenAI 키 대신 ChatGPT 플랜 쓰기"). 줄마다 `연결됨` 또는 `키 없음`과 `키 넣기`(키가 있으면 `다시 확인`, `키 바꾸기`, `키 지우기`)가 있다. 연결된 줄에는 `마지막 확인` 시각이 보이고, `다시 확인`은 넣어 둔 키를 다시 확인한다. 실패하면 줄에 `확인 실패`와 까닭이 보이지만 키는 지워지지 않는다.
- `면접에 쓰는 모델`: 접힌 묶음. [interview.md](interview.md#일마다의-모델과-비용)에 있다.
- `문서`: `입력하면서 자동 서식` 스위치([writing.md](writing.md#입력하면서-자동-서식))와 `새 문서의 스타일`([writing.md](writing.md#스타일)).
- `Figma`: `Figma 데스크톱 앱`(`설치됨` 또는 `없음`과 `Figma 받기`), `중계`(`꺼짐`·`켜짐`·`실패`와 `중계 켜기`), `플러그인`(`경로 복사`), `채널`(채널 ID 칸, `연결`, 상태 `연결 안 됨`·`연결 중`·`연결됨`·`실패`). [canvas.md](canvas.md#figma로-보내기)에 있다.
- `개인정보`: 연락처 가리기 안내와 `시선 기록` 스위치. [privacy.md](privacy.md)에 있다.
- `업데이트`: 지금 쓰는 판, `지금 확인` 단추, `자동으로 업데이트 확인` 스위치. 위의 "업데이트"에 있다.

비용
- 면접에 드는 비용은 본인의 API 요금으로 그 제공사에 나간다. Kari가 받는 돈은 없다.
- 기본값으로 10분 연습 한 번에 Claude는 0.015달러, OpenAI는 0.008달러 안팎이 든다(2026년 11월에 Claude Haiku 5.5, GPT-6 Luna로 잰 값). 리포트의 "이번 연습"에 그 연습의 추정 비용이 보인다.
- 일마다 제공사, 모델, 추론 강도를 고르는 법과 기본값은 [interview.md](interview.md#일마다의-모델과-비용)에 있다.
- 사용량과 요금은 각 제공사의 콘솔에서 본다.
- OpenAI를 ChatGPT 플랜으로 쓰면 API 요금이 나가지 않고 그 사용량이 ChatGPT 플랜(또는 크레딧)에서 빠진다. ChatGPT 설정의 사용량에서 본다.


## 6. 무엇이 기기 밖으로 나가나요

- 면접 연습을 할 때만, 고른 이력서의 글, 붙여넣은 채용공고, 면접에서 쓴 답변이 일마다 고른 AI 제공사(Anthropic 또는 OpenAI)로 간다. 연락처는 가려서 보낸다.
- 시선 기록의 카메라 영상은 이 맥 밖으로 나가지 않는다.
- 자세한 것은 [privacy.md](privacy.md)에 있다.


## 7. 자료의 위치와 지우는 법

- 문서, 버전, 면접 기록은 모두 이 맥 안에 있다:
  ~/Library/Containers/dev.clonamic.kari/
  (Finder의 "이동" 메뉴 → "폴더로 이동"에 위 주소를 넣으면 열린다. Finder에서는 폴더 이름이 "Kari"로 보일 수 있다.)
- 하루에 한 번(켤 때, 그리고 켜 둔 채 고치다가 쉬거나 문서를 닫을 때) 자료를 백업하고 최근 10개를 남긴다. 그림 파일은 백업에 들어가지 않는다.
- 자료 파일이 손상돼 열리지 않으면 시작 화면에 "백업에서 되살리기"가 보인다. 가장 최근 백업으로 되살리고, 손상된 파일은 폴더에 그대로 남겨 둔다. 백업 뒤에 고친 내용은 되살아나지 않는다.
- 문서 하나가 손상돼 열리지 않으면 오류 줄의 "남은 내용으로 사본 만들기"가 남은 내용으로 새 문서("… 되살린 사본")를 만들어 연다. 원래 문서는 그대로 둔다.
- 모두 지우려면
  1. 키를 넣었다면 먼저 Kari의 "설정" → "AI 연결"에서 제공사마다 "키 지우기"를 누른다.
  2. Kari를 끝낸다(⌘Q).
  3. 응용 프로그램 폴더의 Kari를 휴지통으로 옮긴다.
  4. 위의 ~/Library/Containers/dev.clonamic.kari 폴더를 휴지통으로 옮기고 휴지통을 비운다.
- 한 자료 폴더는 Kari 하나만 연다. 이미 켜 둔 Kari가 있는데 Kari를 또 열면 "다른 Kari가 이 자료를 쓰고 있습니다"가 보인다. 앞의 Kari를 끈 뒤 `다시 시도`를 누르면 열린다.
- Kari가 자료를 열지 못하면 까닭, 자료 폴더의 자리, 할 일이 화면에 보인다. `자료 폴더 열기`는 그 폴더를 Finder 창으로 보인다. 열지 못하면 화면에 적힌 경로를 Finder의 "폴더로 이동"에 넣어 연다. 폴더 안의 `backups`에는 Kari가 하루에 한 번까지 만들어 둔 사본이 최근 10개까지 있다.
- 키를 지우지 않고 앱부터 지웠다면 "키체인 접근" 앱에서 이름이 dev.clonamic.kari인 항목을 모두 지운다.


## 8. 지원 범위

- 글꼴: 앱에 든 글꼴(Pretendard)로 쓰고 그린다. 이 글꼴에 없는 글자(한자, 이모지 등)는 빈 네모로 표시하고, 문서 화면에 그 글자 수를 알린다.
- 머리글·바닥글은 쪽 설정 창에서 고친다.
- Word 문서로 내보낼 때 글꼴은 담지 않는다. 문단의 테두리에서 글과 선 사이의 거리는 1pt 단위로 반올림한다.
- 면접은 백엔드 개발 직무를 다루고, 글로 주고받는다.
- 다른 앱의 파일은 Word 문서(DOCX), HTML, Google Docs의 웹 페이지 꾸러미(zip)를 새 글 문서로 가져온다. PDF와 그 밖의 형식은 아직 가져오지 않는다. 글꼴은 Pretendard로 바꾸고, 옮기지 못한 것은 가져오기 전에 보인다.
- 면접에 쓰는 AI 제공사는 Anthropic(Claude)과 OpenAI이다.
- 화면과 문서는 한국어이다.
