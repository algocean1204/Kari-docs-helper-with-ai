# Kari 설치와 처음 여는 법

Kari(카리)는 이력서를 쓰고, 그 이력서와 채용공고로 기술 면접을 글로 연습하는 맥 앱입니다.


## 1. 필요한 기기

- Apple Silicon 맥(M1, M2, M3, M4 등)
- macOS 13(Ventura) 이상
- 내 맥의 칩과 macOS 판은 화면 왼쪽 위의 사과 메뉴 → "이 Mac에 관하여"에서 볼 수 있습니다.


## 2. 설치

1. 받은 `.dmg` 파일을 두 번 누릅니다. 창이 하나 열립니다.
2. 창 안의 `Kari`를 옆의 `Applications`(응용 프로그램) 폴더 위로 끌어다 놓습니다.
3. 창을 닫고, Finder 옆 막대의 디스크(Kari) 옆 꺼내기 단추를 누릅니다.


## 3. 처음 여는 법

이 판은 Apple 공증 없이 배포됩니다. 그래서 처음 열 때 macOS가 앱을 막고, 한 번 허락하면 그다음부터는 그냥 열립니다.
방법은 macOS 판에 따라 다릅니다.

macOS 15(Sequoia) 이상
1. 응용 프로그램 폴더에서 Kari를 두 번 눌러 엽니다. 경고 창이 뜨면 "완료"를 누릅니다(휴지통으로 옮기지 마세요).
2. 사과 메뉴 → 시스템 설정 → 개인정보 보호 및 보안으로 갑니다.
3. 아래로 내려 "보안" 부분에서 Kari 옆의 "그래도 열기"를 누릅니다.
4. 맥의 암호(또는 Touch ID)를 넣고, 다시 뜨는 창에서 "그래도 열기"를 누릅니다.
5. "그래도 열기" 단추는 막힌 뒤 한 시간쯤만 보입니다. 안 보이면 1번부터 다시 합니다.

macOS 13(Ventura), 14(Sonoma)
1. 응용 프로그램 폴더에서 Kari를 Control 키를 누른 채 누릅니다(또는 오른쪽 단추로 누릅니다).
2. 나온 메뉴에서 "열기"를 누릅니다.
3. 경고 창에서 다시 "열기"를 누릅니다.
4. 열리지 않으면 위의 "macOS 15 이상" 방법(시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기)을 씁니다.


## 4. 할 수 있는 것

- 문서 만들기, 이름 바꾸기, 복제, 휴지통
- 글쓰기와 한글 입력
- 글자 모양(크기, 굵게·기울임·밑줄·취소선, 글자색, 형광펜, 위·아래 첨자, 자간, 대소문자, 서식 지우기)과 문단 모양(정렬, 들여쓰기, 문단 간격, 줄 간격, 쪽 나누기, 테두리와 바탕)
- 스타일(고치기, 새 스타일, 새 문서의 기본 스타일)
- 입력하면서 자동 서식(목록, 제목, 주소를 링크로)
- 목록(번호 시작 값), 탭 정지, 링크, 가로줄, 오늘 날짜
- 표(칸마다 선과 바탕, 표 속성, 경계를 끌어 열 폭·행 높이 바꾸기, 셀 합치기, 쪽이 넘어가면 머리 행 반복, 표와 칸 복사·붙여넣기)
- 그림(PNG, JPEG)
- 찾기·바꾸기(낱말 단위), 글자 수와 낱말 수, 개요, 쪽으로 가기
- 쪽 설정(용지 크기와 방향, 사용자 지정 용지, 여백), 머리글·바닥글, 쪽 번호
- 되돌리기·다시 하기, 자동 저장, 버전(예전 상태로 돌아가기)
- PDF로 내보내기(링크가 눌리고 글자를 고르고 찾을 수 있는 PDF), Word 문서(DOCX)와 텍스트로 내보내기
- 인쇄, 공유, 보기 배율(50~300%, 쪽 너비에 맞춤), macOS 메뉴 막대
- 채용공고 붙여넣기
- 글로 하는 면접 연습과 리포트(백엔드 개발 직무)
- 홈에서 이력서의 주장 가운데 면접에서 방어한 수와 먼저 준비할 주장 보기
- 시선 기록: 면접 중에 화면을 보고 있는지만 봅니다(카메라를 씁니다. 준비 화면과 설정에서 끌 수 있습니다)

저장 단추는 없습니다. 고칠 때마다 저장됩니다. 자세한 쓰는 법은 [writing.md](writing.md)와 [interview.md](interview.md)에 있습니다.


## 5. AI 키 넣기와 비용 (면접 연습에만 필요)

문서 쓰기와 PDF 내보내기는 키 없이 됩니다. 면접 연습에는 본인의 Anthropic(Claude) 또는 OpenAI API 키가 필요합니다. 둘 중 하나만 있어도 됩니다.

1. 쓸 제공사의 개발자 콘솔(Anthropic은 https://console.anthropic.com, OpenAI는 https://platform.openai.com)에서 가입하고 결제 수단을 등록한 뒤 API 키를 만듭니다.
2. Kari의 옆 메뉴에서 "설정" → "AI 연결"의 그 제공사 줄(Claude 또는 OpenAI)에서 "키 넣기"를 누르고, 키를 붙여넣은 뒤 "확인하고 저장"을 누릅니다.
3. 키는 제공사마다 따로 넣고 지웁니다. 키는 이 맥의 키체인에만 둡니다.

"설정" 화면에는 위에서부터 이런 묶음이 있습니다.
- `AI 연결`: Claude와 OpenAI 두 줄. 줄마다 `연결됨` 또는 `키 없음`과 `키 넣기`(키가 있으면 `키 바꾸기`, `키 지우기`)가 있습니다.
- `일마다의 모델`: 접힌 묶음. [interview.md](interview.md#일마다의-모델과-비용)에 있습니다.
- `문서`: `입력하면서 자동 서식` 스위치([writing.md](writing.md#입력하면서-자동-서식))와 `새 문서의 스타일`([writing.md](writing.md#스타일)).
- `개인정보`: 연락처 가리기 안내와 `시선 기록` 스위치. [privacy.md](privacy.md)에 있습니다.

비용
- 면접에 드는 비용은 본인의 API 요금으로 그 제공사에 나갑니다. Kari가 받는 돈은 없습니다.
- 기본값으로 10분 연습 한 번에 Claude는 0.015달러, OpenAI는 0.008달러 안팎이 듭니다(2026년 11월에 Claude Haiku 5.5, GPT-6 Luna로 잰 값). 리포트의 "이번 연습"에 그 연습의 추정 비용이 보입니다.
- 일마다 제공사, 계열, 추론 강도를 고르는 법과 기본값은 [interview.md](interview.md#일마다의-모델과-비용)에 있습니다.
- 사용량과 요금은 각 제공사의 콘솔에서 봅니다.


## 6. 무엇이 기기 밖으로 나가나요

- 면접 연습을 할 때만, 고른 이력서의 글, 붙여넣은 채용공고, 면접에서 쓴 답변이 일마다 고른 AI 제공사(Anthropic 또는 OpenAI)로 갑니다. 연락처는 가려서 보냅니다.
- 시선 기록의 카메라 영상은 이 맥 밖으로 나가지 않습니다.
- 자세한 것은 [privacy.md](privacy.md)에 있습니다.


## 7. 자료의 위치와 지우는 법

- 문서, 버전, 면접 기록은 모두 이 맥 안에 있습니다:
  ~/Library/Containers/dev.clonamic.kari/
  (Finder의 "이동" 메뉴 → "폴더로 이동"에 위 주소를 넣으면 열립니다. Finder에서는 폴더 이름이 "Kari"로 보일 수 있습니다.)
- 모두 지우려면
  1. 키를 넣었다면 먼저 Kari의 "설정" → "AI 연결"에서 제공사마다 "키 지우기"를 누릅니다.
  2. Kari를 끝냅니다(⌘Q).
  3. 응용 프로그램 폴더의 Kari를 휴지통으로 옮깁니다.
  4. 위의 ~/Library/Containers/dev.clonamic.kari 폴더를 휴지통으로 옮기고 휴지통을 비웁니다.
- 키를 지우지 않고 앱부터 지웠다면 "키체인 접근" 앱에서 이름이 dev.clonamic.kari인 항목을 모두 지웁니다.


## 8. 지원 범위

- 글꼴: 앱에 든 글꼴(Pretendard)로 쓰고 그립니다. 이 글꼴에 없는 글자(한자, 이모지 등)는 빈 네모로 표시하고, 문서 화면에 그 글자 수를 알립니다.
- 머리글·바닥글은 쪽 설정 창에서 고칩니다.
- Word 문서로 내보낼 때 글꼴은 담지 않습니다. 문단의 테두리에서 글과 선 사이의 거리는 1pt 단위로 반올림합니다.
- 면접은 백엔드 개발 직무를 다루고, 글로 주고받습니다.
- 면접에 쓰는 AI 제공사는 Anthropic(Claude)과 OpenAI입니다.
