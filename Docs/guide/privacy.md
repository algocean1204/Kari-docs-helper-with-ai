# 개인정보: 무엇이 기기 밖으로 나가나

Kari의 서버는 없다. 기기 밖으로 나가는 것은 사용자가 넣은 API 키로 AI 제공사에 직접 보내는 요청과, 앱 안에서 업데이트할 수 있는 판이 새 판이 있는지 GitHub에 묻는 업데이트 확인뿐이다. `Figma로 보내기`는 이 맥 안의 Figma 데스크톱 앱에 넘기는 것이고, 그 뒤는 Figma가 다룬다(아래 "Figma로 보내기"). 제공사는 Anthropic(`api.anthropic.com`)과 OpenAI(`api.openai.com`)이고, 키를 넣은 제공사에만 보낸다.

## 1. 보내는 것

| 언제 | 어디로 | 무엇을 |
|---|---|---|
| 설정에서 키를 넣을 때 | 그 키의 제공사 | 키가 맞는지 확인하는 모델 목록 요청. 문서 내용은 가지 않음 |
| 앱을 열 때, 받아 둔 모델 목록이 하루보다 오래됐으면 | 키가 있는 제공사 | 모델 목록 요청. 문서 내용은 가지 않음 |
| 면접 연습을 할 때 | 일마다 고른 제공사 | 고른 이력서의 글, 붙여넣은 채용공고, 면접에서 쓴 답변, 질문을 만들고 채점하는 데 쓰는 지시문과 지식 팩의 일부 |
| 업데이트 확인(`자동으로 업데이트 확인`이 켜져 있으면 24시간에 한 번까지, 그리고 메뉴의 `Kari` → `업데이트 확인…`을 누를 때) | `github.com`의 Kari 릴리스(`https://github.com/algocean1204/Kari-docs-helper-with-ai/releases/latest/download/appcast.xml`. GitHub가 내려받는 주소로 넘김) | 그 주소에 대한 GET 요청 하나. 사용자 에이전트 `Kari/<판> Sparkle/<판>`(예: `Kari/0.1.0 Sparkle/2.9.6`)와 macOS가 붙이는 보통의 머리글(받을 언어 등). 문서, 이력서, 키, 기기 정보는 가지 않음 |
| `Figma로 보내기`에서 `자리 지시`를 쓰고 키가 있을 때 | 키가 있는 제공사(Claude 키가 있으면 Anthropic, 없으면 OpenAI) | 대지마다의 크기와 노드 수, 종류마다의 수, 연결된 Figma 파일의 페이지 이름, 고른 페이지와 그 빈 자리의 좌표, 지시 글. 문서의 글, 이름, 그림은 가지 않음 |
| `지금 업데이트`를 누를 때 | 같은 릴리스의 업데이트 꾸러미(`Kari-macos-arm64.zip`) | 내려받기 요청. 위와 같은 사용자 에이전트 |

- 면접의 네 가지 일(주장 뽑기, 공고 나누기, 질문 만들기, 답변 채점)은 설정 → `면접에 쓰는 모델`에서 고른 제공사로만 간다. 고른 제공사의 키가 없으면 시작하지 않고, 다른 제공사로 보내지 않는다.
- 처음 면접을 시작할 때는 "보내는 내용" 창이 먼저 뜨고, 그 안의 "시작"을 눌러야 보낸다. 창에 일마다 보낼 제공사의 모델이 보인다. 그 뒤에도 면접 화면의 "보내는 내용 보기"로 볼 수 있다.
- OpenAI에 보내는 요청에는 응답을 OpenAI 서버에 남기지 않도록 요청하는 값(`store: false`)을 넣는다.
- 보내기 전에 연락처를 `〔연락처N〕` 모양의 표시로 바꾸고, 돌아온 결과를 화면에 보일 때 원래 값으로 되돌린다. 이 가리기는 늘 켜져 있고, 두 제공사에 같게 적용된다. 설정 → 개인정보의 `연락처 가리기`에 같은 안내가 있다.

| 가려서 보내는 것 | 그대로 보내는 것 |
|---|---|
| 전자우편 주소(`(at)`·`[at]`으로 풀어 쓴 것, 한글 도메인 포함), 국내 휴대·유선·인터넷 전화번호(`+82`, 괄호로 쓴 지역번호 `(02) 123-4567`, 빈칸·점·빗금으로 나눈 것 포함), 주민등록번호 모양(숫자 6개-숫자 7개, 그리고 생년월일 모양인 붙여 쓴 13자리). 워드나 PDF에서 붙여넣은 다른 붙임표(–)와 전각 숫자도 같게 가린다 | 이름, 학교·회사 이름, 주소, `@` 앞뒤에 빈칸을 둔 주소(예: `직무 @ 회사.도메인`. 회사 표기와 가를 수 없다), 15xx 대표번호, 외국 전화번호, 숫자를 글자로 풀어 쓴 번호(예: `공일공`), 웹 주소(`https://…`) 안의 글 |

- 제공사가 받은 자료를 다루는 방식은 그 제공사의 정책을 따른다.
- 설정 → 업데이트의 `자동으로 업데이트 확인`을 끄면 메뉴에서 `업데이트 확인…`을 누를 때만 묻는다. 앱 안에서 업데이트할 수 없는 판은 묻지 않는다. GitHub가 받은 요청(접속 주소 등)을 다루는 방식은 GitHub의 정책을 따른다.

### Figma로 보내기

| 무엇이 | 어디로 | 길 |
|---|---|---|
| 캔버스 문서의 내용(대지, 도형, 글 상자의 글, 그림 파일, 색과 자리) | 연결한 채널의 Figma 플러그인 | 이 맥 안의 중계(127.0.0.1:3055)를 거친다 |
| 위 1절의 크기·개수 요약과 지시 글 | AI 제공사 | `자리 지시`를 쓰고 키가 있을 때만 |

- 보내기 창에 "Figma로 가는 것"과 "AI로 가는 것"이 먼저 보이고, `보내기`를 눌러야 보낸다.
- Kari가 켠 중계는 127.0.0.1에만 묶어 이 맥 밖에서는 붙을 수 없다. Origin이 `http`, `https`인 연결(웹 페이지)은 받지 않는다. Origin이 없거나 `null`인 연결은 받는다. Figma의 플러그인 창이 이렇게 붙고, 이 맥의 다른 프로그램, 샌드박스로 막힌 웹 프레임, `file://`로 연 페이지도 같은 모양으로 붙을 수 있다.
- 그래서 채널에 들려면 플러그인이 무작위로 만든 채널 ID(영문 소문자와 숫자 8자)를 알아야 한다. 중계는 채널 목록을 알려 주지 않고, 한 연결은 채널 하나에만 든다. 압축한 메시지는 받지 않고, 32MB를 넘는 메시지는 넘기지 않으며, 동시에 16개 연결까지만 받는다. Kari를 끄면 꺼진다.
- 3055 자리에 이미 다른 중계가 켜져 있으면(예: 플러그인의 원래 중계 서버) Kari는 그것을 쓴다. 그 중계가 받는 주소(모든 주소일 수 있다), Origin 검사, 메시지 한도는 그것을 켠 프로그램이 정하고, 위의 Kari 중계 규칙은 적용되지 않는다. 설정 → Figma의 `중계` 줄에 어느 쪽인지 보인다.
- Kari가 Figma에 보내는 명령은 만들기, 값 바꾸기, 옮기기, 크기 바꾸기, 페이지 만들기와 읽기뿐이다. 지우는 명령은 보내지 않는다.
- Figma 파일에 들어간 내용은 Figma의 파일이 되고, 그 뒤의 저장과 공유는 Figma의 정책을 따른다.
- 플러그인 파일은 자료 폴더의 `figma-plugin/`에 쓰고, 마지막으로 연결한 채널 ID는 설정에 둔다.

## 2. 보내지 않는 것

- 사용 기록, 오류 보고, 통계. Kari는 이런 것을 모으지 않는다.
- 면접 연습 밖의 문서 내용. 문서 쓰기, 버전, 내보내기(PDF, Word 문서, 텍스트)는 모두 기기 안에서 한다. 인쇄와 공유는 만든 PDF를 macOS의 인쇄 창과 공유 메뉴에 넘기는 데까지이고, 그 뒤는 사용자가 고른 프린터나 공유 서비스가 다룬다.
- 카메라 영상. 아래 "시선 기록과 카메라"를 본다.
- API 키. 키는 제공사마다 macOS 키체인(서비스 이름 `dev.clonamic.kari`, 계정 이름은 제공사 `anthropic`, `openai`)에만 두고, 그 제공사의 API를 부를 때의 인증 머리글로만 쓴다. 문서 DB, 설정 파일, 로그, 오류 문구에 쓰지 않는다.

기기 안에 두는 것:

| 무엇 | 어디 |
|---|---|
| 문서, 버전, 그림, 채용공고, 면접 기록과 리포트, 시선 기록의 구간, 설정(일마다의 모델, 받아 둔 모델 목록 포함) | `~/Library/Containers/dev.clonamic.kari/`(앱 샌드박스 컨테이너) |
| Anthropic, OpenAI API 키 | macOS 키체인 |

## 3. 시선 기록과 카메라

면접 연습의 시선 기록이 켜져 있을 때만 카메라를 쓴다([interview.md](interview.md#시선-기록)).

| 항목 | 내용 |
|---|---|
| 켜지는 때 | 면접 진행 화면이 보이고 연습이 끝나지 않은 동안. 연습이 끝나거나, 화면을 떠나거나, 기록을 끄면 카메라를 닫는다 |
| 보는 것 | 초당 5장을 이 맥 안에서 macOS의 Vision으로 보고, 얼굴이 있는지와 얼굴의 좌우·상하 각도만 뽑는다 |
| 저장하는 것 | 화면 밖을 10초 이상 본 구간의 질문 번호와 시작·끝 시각, 시선 기록을 켜 둔 시간의 합. 면접 기록과 함께 둔다 |
| 저장하지 않는 것 | 카메라 영상과 사진. 로그에도 남기지 않는다 |
| 밖으로 나가는 것 | 없다. 구간도 AI 제공사에 보내지 않는다 |

- 카메라 권한은 macOS의 시스템 설정 → 개인정보 보호 및 보안 → 카메라에서 거둘 수 있다.

## 4. 끄는 법과 지우는 법

- 키를 넣지 않으면 아무것도 기기 밖으로 나가지 않는다. 문서 쓰기, 내보내기, 인쇄, 공유는 키 없이 된다.
- 넣은 키는 설정 → AI 연결에서 제공사마다 "키 지우기"로 지운다. 그 뒤로 그 제공사로는 아무것도 나가지 않는다.
- 모든 자료를 지우는 법은 [install.md](install.md#7-자료의-위치와-지우는-법)에 있다.

## 앱의 권한

| 권한 | 쓰는 곳 |
|---|---|
| 앱 샌드박스 | 앱은 자기 컨테이너 밖의 파일에 닿지 않는다 |
| 밖으로 나가는 네트워크 연결 | 1절의 AI 제공사(Anthropic, OpenAI) API 호출과 업데이트 확인·내려받기, Figma 연결의 중계(127.0.0.1)에 붙기 |
| 들어오는 네트워크 연결 | Figma 연결의 중계(Kari가 켤 때). 127.0.0.1:3055에만 묶는다 |
| 업데이트 설치 도구와의 연결(`dev.clonamic.kari-spks`, `dev.clonamic.kari-spki`) | 샌드박스 밖의 설치 도구(Sparkle)가 받은 새 판의 서명을 확인하고 설치된 Kari를 바꾼다 |
| 사용자가 고른 파일 읽고 쓰기 | 내보낸 파일(PDF, Word 문서, 텍스트) 저장, 그림 열기 |
| 카메라 | 3절의 시선 기록 |
| 인쇄 | 인쇄 창 |

문서 안의 링크나 리포트의 출처 주소를 누르면 macOS의 기본 브라우저가 그 주소를 연다.
