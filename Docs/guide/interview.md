# 면접 연습

내 이력서와 지원할 채용공고로 기술 면접을 글로 연습한다. 질문을 하나씩 받고 글로 답하면, 끝난 뒤 리포트가 나온다. 면접은 백엔드 개발 직무를 다룬다.

## 홈

홈 맨 위에는 지금 상태에 맞는 카드 하나가 있다. 위에서부터 먼저 맞는 것 하나가 보인다.

| 상태 | 카드 | 단추 |
|---|---|---|
| 끝나지 않은 면접이 있음 | "하던 면접이 있습니다": 문서, 질문 번호, 남은 시간 | `이어서 하기` |
| 마친 면접이 있음 | 마지막으로 면접을 마친 문서(와 그때 쓴 공고)의 진행: 이력서의 주장 가운데 방어한 수, 먼저 준비할 주장 최대 2개 | `면접 연습 시작`(그 문서와 공고를 골라 둠), `이어서 쓰기` |
| 흐름 문서가 있고 일마다 고른 제공사의 키가 모두 있음 | "이 이력서로 면접을 연습할 수 있습니다" | `면접 연습 시작`, `이어서 쓰기` |
| 흐름 문서만 있음 | 최근에 고친 문서 | `이어서 쓰기` |
| 문서가 없음 | "이력서부터 씁니다" | `새 문서` |

- **주장**은 면접을 시작할 때 이력서에서 뽑은 문장(쓴 기술, 겪은 문제, 낸 결과)이다. 주장마다 이어진 주제의 가장 최근 결과로 상태가 정해진다.

| 주장의 상태 | 조건 |
|---|---|
| 방어함 | 물은 주제가 모두 목표 깊이에 닿았다 |
| 일부 방어 | 닿은 주제와 못 닿은 주제가 섞였거나, 못 닿은 주제에 첫 통과까지 간 관점이 있다 |
| 방어 못 함 | 물은 주제가 모두 목표 깊이에 닿지 못했고, 첫 통과까지 간 관점도 없다 |
| 안 물음 | 이어진 주제를 물은 적이 없다 |

- 먼저 준비할 주장은 방어 못 함, 일부 방어 순이고, 줄마다 빠진 내용 한 줄이 붙는다. 줄을 누르면 그 면접의 리포트로, `이력서에서 보기`를 누르면 문서의 그 문장으로 간다.
- 이력서에서 지식 팩의 주제에 이어진 주장이 없으면 "이력서에서 연결된 주제를 찾지 못했습니다"와 지난 면접의 주제별 깊이가 보인다.
- 카드 아래 준비 줄(이력서, AI 연결, 채용공고, 첫 연습)은 끝나지 않은 단계를 누르면 그 일을 하러 가고, 모두 끝나면 사라진다. 그 아래에 문서와 공고 목록이 있다.

## 준비

| 준비할 것 | 하는 곳 | 꼭 있어야 하나 |
|---|---|---|
| AI 제공사의 API 키(Anthropic 또는 OpenAI) | 설정 → AI 연결 → 그 제공사 줄(Claude, OpenAI)의 "키 넣기" | 예 |
| 이력서 | Kari에서 쓴 문서 | 예 |
| 채용공고 | 홈이나 면접 화면의 "공고 추가"에 공고 글 전체를 붙여넣음(20,000자까지) | 아니오 |

- 키를 만들고 넣는 법은 [install.md](install.md#5-ai-키-넣기와-비용-면접-연습에만-필요)에 있다. 일마다 고른 제공사의 키가 모두 있어야 시작할 수 있다. 없으면 면접 화면에 "AI 연결이 필요합니다"가 보인다.
- 채용공고가 있으면 공고가 요구하는 연차와 기술에 맞춰 질문의 깊이를 정한다. 채용 사이트에서 공고를 가져오지 않는다. 붙여넣은 글만 쓴다.

## 시작

면접 화면에서 고른다. 시간, 압박, 시선 기록은 `옵션` 묶음 안에 있다.

| 항목 | 고를 수 있는 것 |
|---|---|
| 이력서 | 문서 하나 |
| 채용공고 | 추가한 공고 하나 또는 없음 |
| 연차 | 신입, 1~3년, 4년 이상 |
| 시간 | 10분, 12분, 15분(주제는 10·12분이 3개, 15분이 4개) |
| 압박 | 코칭, 표준, 실전 |
| 시선 기록 | 켬, 끔(아래 "시선 기록") |

| 압박 | 묻는 방식 | 힌트 |
|---|---|---|
| 코칭 | 부드럽게 묻고, 답 뒤에 짚은 핵심의 수를 보여 준다 | 질문마다 한 번 |
| 표준 | 꼬리질문과 반박을 한다 | 주제마다 한 번 |
| 실전 | 짧고 건조하게 묻고 반박을 먼저 한다 | 없음 |

### 보내는 내용

처음 시작할 때는 "보내는 내용" 창이 먼저 뜬다. 창 안의 "시작"을 눌러야 보낸다. 그 뒤에도 "보내는 내용 보기"로 언제든 볼 수 있다.

| 창에 보이는 것 | 내용 |
|---|---|
| 일마다의 모델 | 이력서 주장 뽑기, 채용공고 나누기, 질문 만들기, 답변 채점마다 이 연습에 쓸 모델과 실제로 보내는 추론 강도 |
| 연락처 | 가린 연락처의 수. 전자우편, 전화번호, 주민등록번호 모양은 `〔연락처N〕` 표시로 바꿔 보낸다 |
| 이력서 | 보낼 이력서 글(가린 뒤) |
| 채용공고 | 보낼 공고 글(가린 뒤). 공고를 고르지 않았으면 이 칸이 없다 |

면접 중의 답도 같은 방식으로 가려서 보낸다. 무엇이 기기 밖으로 나가는지는 [privacy.md](privacy.md)에 있다.

## 진행

| 동작 | 방법 |
|---|---|
| 답하기 | 답을 쓰고 ⌘Enter 또는 "답변 내기". Enter는 줄바꿈. 답은 4,000자까지 |
| 모를 때 | "모르겠습니다". 그 관점은 실패로 기록하고, 연습마다 한 번 "모를 때 어떻게 접근하는지"를 묻는다 |
| 힌트 | "힌트"(남은 수가 단추에 보인다). 같은 질문에 실마리가 붙는다. 꼬리질문에서 힌트를 쓰면 그 관점은 첫 통과까지만 인정한다 |
| 앞선 문답 보기 | "앞선 문답 N개 보기" |
| 끝내기 | "끝내기". 지금까지의 답으로 리포트를 만든다 |

- 질문은 한 번에 하나다. 주제마다 목표 깊이가 있고(연차와 공고로 정함), 꼬리질문까지 버틴 답만 그 깊이로 인정한다. 좋은 답에는 같은 주제를 더 깊게, 막히면 더 기본적인 쪽으로 묻고, 답한 내용에 반대되는 말이 있으면 반례를 묻는다.
- 남은 시간이 화면에 보인다. 시간이 다 되거나 정한 주제를 다 물으면 끝난다.
- 앱을 닫거나 오류로 멈춘 연습은 홈이나 면접 화면의 "이어서 하기", 오류 안내의 "다시 시도"로 멈춘 곳부터 이어 간다.

## 시선 기록

면접 중에 카메라로 얼굴이 화면 쪽을 보고 있는지만 보고, 화면 밖을 10초 이상 본 구간을 리포트에 남긴다. 점수와 깊이에는 들지 않는다.

- 켜고 끄기: 면접 화면의 `옵션` → `시선 기록`, 또는 설정 → 개인정보 → `시선 기록`(같은 값이다). 처음에는 켜져 있다. 진행 중에는 위쪽의 `시선 기록 끄기`로 그 연습에서만 끈다.
- 처음 켤 때 macOS가 카메라 권한을 묻는다. 권한이 없거나 카메라가 없으면 시선 기록 없이 진행하고 그 까닭을 알린다. 권한이 없을 때는 `시스템 설정 열기`가 보인다.
- 카메라는 진행 화면이 보이고 연습이 끝나지 않은 동안만 켜진다. 켜진 동안 위쪽에 "시선 기록 중"이 보인다.
- 세지 않는 때: 질문이 뜬 뒤 15초, 답 칸에서 마지막으로 글쇠를 누른 뒤 5초, 답을 낸 뒤 다음 질문이 뜰 때까지, Kari 창이 앞에 있지 않을 때.
- 리포트의 `화면 밖 10초 이상`에 구간마다 질문 번호와 길이(초)가 나온다. 구간이 없으면 이 묶음은 보이지 않는다.
- 카메라 영상은 저장하지 않고 기기 밖으로 보내지 않는다. 남는 것은 [privacy.md](privacy.md#3-시선-기록과-카메라)에 있다.

## 리포트

리포트 화면에서 연습 기록을 고르면 나온다. 리포트는 채점 결과와 앱에 든 지식 팩으로 만든다.

| 자리 | 내용 |
|---|---|
| 큰 카드 | `먼저 고칠 것` 하나: 주제와 관점, 질문, 내 답, 다음에 말할 것(빠진 내용과 출처), 다음 행동. 카드의 `이 주제로 다시 연습`은 면접 준비로 가며 그 연습의 문서와 공고를 골라 둔다 |
| 그 아래 줄 | 나머지 먼저 고칠 것(최대 2개). 누르면 같은 내용이 펼쳐진다 |
| 접힌 묶음(제목 옆에 개수) | 바로잡을 것(틀린 생각, 바른 설명, 내 답, 출처), 잘한 점(꼬리질문까지 버틴 관점), 주제별 깊이(주제마다 목표와 도달한 깊이, 관점별 상태: 확인됨, 첫 통과에 그침 또는 실패, 안 물음), 화면 밖 10초 이상. 내용이 없는 묶음은 보이지 않는다 |
| 다음에 다시 낼 주제 | 목표에 못 미친 주제 |
| 이번 연습 | 걸린 시간, 질문 수, 인용 확인 실패 수, 토큰 수, 추정 비용(미화), 쓴 모델 |

출처는 제목과 주소로 보인다. "주소 열기"를 누르면 기본 브라우저가 연다.

## 일마다의 모델과 비용

설정 → `일마다의 모델`(접힌 묶음)에는 이력서 주장 뽑기, 채용공고 나누기, 질문 만들기, 답변 채점의 네 줄이 있다. 줄마다 계열, 실제로 보낼 추론 강도, 지금 정해진 판이 보이고, 고른 제공사의 키가 없으면 `키 없음`이 붙는다. 접혀 있을 때는 `기본값 사용 중`, `N개 바꿈`, 키가 하나도 없으면 `키를 넣으면 고를 수 있습니다`가 보인다.

- `바꾸기`에서 그 일의 제공사(Claude, OpenAI), 계열(Claude: Haiku, Sonnet, Opus / OpenAI: Luna, Terra, Sol), 추론 강도(낮음, 보통, 높음, 매우 높음, 최대)를 고른다. 고르면 바로 저장된다.
- 판은 고르지 않는다. 그 제공사의 키로 받은 모델 목록에서 그 계열의 가장 새 판을 쓰고, 정해진 판이 화면에 보인다.
- 추론 강도는 그 판이 받는 단계로 맞춰 보내고, 실제로 보낼 값이 화면에 보인다.
- `기본값으로 되돌리기`는 네 일을 모두 기본값으로 돌린다.
- 연습 하나는 시작할 때 정해진 제공사, 판, 강도를 끝까지 쓴다. 바꾼 값은 다음 연습부터 쓰인다.
- 고른 제공사의 키가 없으면 연습을 시작하지 않는다. 다른 제공사로 넘어가지 않는다.

저장한 설정이 없을 때의 기본값은 키에 따라 정해진다. Claude 키가 있거나 키가 하나도 없으면 Claude 기본값, OpenAI 키만 있으면 OpenAI 기본값을 쓴다.

| 일 | Claude 기본값 | OpenAI 기본값 |
|---|---|---|
| 이력서 주장 뽑기 | Haiku, 보통 | Luna, 낮음 |
| 채용공고 나누기 | Haiku, 보통 | Luna, 낮음 |
| 질문 만들기 | Haiku, 보통 | Luna, 낮음 |
| 답변 채점 | Haiku, 높음 | Luna, 보통 |

- 백만 토큰당 가격은 Haiku, Sonnet, Opus 순, Luna, Terra, Sol 순으로 높고, 추론 강도가 높을수록 느리고 비용이 더 든다. 기본값으로 10분 연습 한 번의 비용은 [install.md](install.md#5-ai-키-넣기와-비용-면접-연습에만-필요)에 있다.
- 리포트의 `이번 연습`에 그 연습의 토큰 수, 추정 비용, 쓴 모델이 나온다. 가격을 모르는 판을 쓴 연습은 `추정 비용 알 수 없음`으로 보인다. 실제 요금과 사용량은 제공사의 콘솔에서 본다.
