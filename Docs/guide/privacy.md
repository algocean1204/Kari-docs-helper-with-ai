# 개인정보: 무엇이 기기 밖으로 나가나

Kari의 서버는 없습니다. 기기 밖으로 나가는 것은 사용자가 넣은 API 키로 AI 제공사에 직접 보내는 아래 요청뿐입니다. 제공사는 Anthropic(`api.anthropic.com`)과 OpenAI(`api.openai.com`)이고, 키를 넣은 제공사에만 보냅니다.

## 1. 보내는 것

| 언제 | 어디로 | 무엇을 |
|---|---|---|
| 설정에서 키를 넣을 때 | 그 키의 제공사 | 키가 맞는지 확인하는 모델 목록 요청. 문서 내용은 가지 않음 |
| 앱을 열 때, 받아 둔 모델 목록이 하루보다 오래됐으면 | 키가 있는 제공사 | 모델 목록 요청. 문서 내용은 가지 않음 |
| 면접 연습을 할 때 | 일마다 고른 제공사 | 고른 이력서의 글, 붙여넣은 채용공고, 면접에서 쓴 답변, 질문을 만들고 채점하는 데 쓰는 지시문과 지식 팩의 일부 |

- 면접의 네 가지 일(주장 뽑기, 공고 나누기, 질문 만들기, 답변 채점)은 설정 → `면접에 쓰는 모델`에서 고른 제공사로만 갑니다. 고른 제공사의 키가 없으면 시작하지 않고, 다른 제공사로 보내지 않습니다.
- 처음 면접을 시작할 때는 "보내는 내용" 창이 먼저 뜨고, 그 안의 "시작"을 눌러야 보냅니다. 창에 일마다 보낼 제공사의 모델이 보입니다. 그 뒤에도 면접 화면의 "보내는 내용 보기"로 볼 수 있습니다.
- OpenAI에 보내는 요청에는 응답을 OpenAI 서버에 남기지 않도록 요청하는 값(`store: false`)을 넣습니다.
- 보내기 전에 연락처를 `〔연락처N〕` 모양의 표시로 바꾸고, 돌아온 결과를 화면에 보일 때 원래 값으로 되돌립니다. 이 가리기는 늘 켜져 있고, 두 제공사에 같게 적용됩니다. 설정 → 개인정보의 `연락처 가리기`에 같은 안내가 있습니다.

| 가려서 보내는 것 | 그대로 보내는 것 |
|---|---|
| 전자우편 주소(`(at)`·`[at]`으로 풀어 쓴 것, 한글 도메인 포함), 국내 휴대·유선·인터넷 전화번호(`+82`, 괄호로 쓴 지역번호 `(02) 123-4567`, 빈칸·점·빗금으로 나눈 것 포함), 주민등록번호 모양(숫자 6개-숫자 7개, 그리고 생년월일 모양인 붙여 쓴 13자리). 워드나 PDF에서 붙여넣은 다른 붙임표(–)와 전각 숫자도 같게 가립니다 | 이름, 학교·회사 이름, 주소, `@` 앞뒤에 빈칸을 둔 주소(예: `직무 @ 회사.도메인`. 회사 표기와 가를 수 없습니다), 15xx 대표번호, 외국 전화번호, 숫자를 글자로 풀어 쓴 번호(예: `공일공`), 웹 주소(`https://…`) 안의 글 |

- 제공사가 받은 자료를 다루는 방식은 그 제공사의 정책을 따릅니다.

## 2. 보내지 않는 것

- 사용 기록, 오류 보고, 통계. Kari는 이런 것을 모으지 않습니다.
- 면접 연습 밖의 문서 내용. 문서 쓰기, 버전, 내보내기(PDF, Word 문서, 텍스트)는 모두 기기 안에서 합니다. 인쇄와 공유는 만든 PDF를 macOS의 인쇄 창과 공유 메뉴에 넘기는 데까지이고, 그 뒤는 사용자가 고른 프린터나 공유 서비스가 다룹니다.
- 카메라 영상. 아래 "시선 기록과 카메라"를 봅니다.
- API 키. 키는 제공사마다 macOS 키체인(서비스 이름 `dev.clonamic.kari`, 계정 이름은 제공사 `anthropic`, `openai`)에만 두고, 그 제공사의 API를 부를 때의 인증 머리글로만 씁니다. 문서 DB, 설정 파일, 로그, 오류 문구에 쓰지 않습니다.

기기 안에 두는 것:

| 무엇 | 어디 |
|---|---|
| 문서, 버전, 그림, 채용공고, 면접 기록과 리포트, 시선 기록의 구간, 설정(일마다의 모델, 받아 둔 모델 목록 포함) | `~/Library/Containers/dev.clonamic.kari/`(앱 샌드박스 컨테이너) |
| Anthropic, OpenAI API 키 | macOS 키체인 |

## 3. 시선 기록과 카메라

면접 연습의 시선 기록이 켜져 있을 때만 카메라를 씁니다([interview.md](interview.md#시선-기록)).

| 항목 | 내용 |
|---|---|
| 켜지는 때 | 면접 진행 화면이 보이고 연습이 끝나지 않은 동안. 연습이 끝나거나, 화면을 떠나거나, 기록을 끄면 카메라를 닫습니다 |
| 보는 것 | 초당 5장을 이 맥 안에서 macOS의 Vision으로 보고, 얼굴이 있는지와 얼굴의 좌우·상하 각도만 뽑습니다 |
| 저장하는 것 | 화면 밖을 10초 이상 본 구간의 질문 번호와 시작·끝 시각, 시선 기록을 켜 둔 시간의 합. 면접 기록과 함께 둡니다 |
| 저장하지 않는 것 | 카메라 영상과 사진. 로그에도 남기지 않습니다 |
| 밖으로 나가는 것 | 없습니다. 구간도 AI 제공사에 보내지 않습니다 |

- 카메라 권한은 macOS의 시스템 설정 → 개인정보 보호 및 보안 → 카메라에서 거둘 수 있습니다.

## 4. 끄는 법과 지우는 법

- 키를 넣지 않으면 아무것도 기기 밖으로 나가지 않습니다. 문서 쓰기, 내보내기, 인쇄, 공유는 키 없이 됩니다.
- 넣은 키는 설정 → AI 연결에서 제공사마다 "키 지우기"로 지웁니다. 그 뒤로 그 제공사로는 아무것도 나가지 않습니다.
- 모든 자료를 지우는 법은 [install.md](install.md#7-자료의-위치와-지우는-법)에 있습니다.

## 앱의 권한

| 권한 | 쓰는 곳 |
|---|---|
| 앱 샌드박스 | 앱은 자기 컨테이너 밖의 파일에 닿지 않습니다 |
| 밖으로 나가는 네트워크 연결 | 1절의 AI 제공사(Anthropic, OpenAI) API 호출 |
| 사용자가 고른 파일 읽고 쓰기 | 내보낸 파일(PDF, Word 문서, 텍스트) 저장, 그림 열기 |
| 카메라 | 3절의 시선 기록 |
| 인쇄 | 인쇄 창 |

문서 안의 링크나 리포트의 출처 주소를 누르면 macOS의 기본 브라우저가 그 주소를 엽니다.
