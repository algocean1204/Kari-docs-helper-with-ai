# 캔버스 문서

캔버스 문서는 페이지 위에 프레임, 사각형, 타원, 선, 글 상자, 그림을 자유롭게 놓는 문서다. 글이 흐르는 문서와 달리 모든 것의 자리와 크기를 정한다. 저장 단추는 없다. 고칠 때마다 저장되고, 화면 위쪽에 "자동 저장됨 · 시각"이 보인다. 저장하지 못했을 때는 글이 흐르는 문서와 같다(기다렸다가 `다시 시도`로 저장하고, 다른 화면으로 가거나 ⌘Q로 앱을 끌 때 저장하지 못한 것이 남으면 묻는다. 그동안 확대와 이동은 된다). 글이 흐르는 문서는 [writing.md](writing.md)에 있다.

## 만들고 열기

| 하려는 것 | 하는 법 |
|---|---|
| 만들기 | 홈의 "새 캔버스". 페이지 하나(1920×1080)가 있는 "제목 없는 캔버스"가 페이지 전체가 보이는 배율로 열린다. 같은 이름이 이미 있으면 "제목 없는 캔버스 2"처럼 번호가 붙는다 |
| 열기 | 홈의 문서 목록에서 누른다. 목록에서 "캔버스"와 "글 문서"는 아이콘과 종류 글로 구분된다 |
| 이름 바꾸기, 복제, 휴지통 | 글이 흐르는 문서와 같다(문서 줄의 더 보기 메뉴, 화면 위쪽의 이름) |

## 화면

| 자리 | 있는 것 |
|---|---|
| 위쪽 줄 | 문서 이름, 저장 상태, 되돌리기, 다시 하기, `PDF로 내보내기`, `버전 기록` 단추, `⋯`(문서 메뉴: `Figma로 보내기…`) |
| 도구 줄 | 왼쪽 끝에 레이어 패널 단추, 고르기, 프레임, 사각형, 타원, 선, 글, 그림. 고른 도구는 바탕이 칠해진다. 오른쪽 끝의 배율 단추는 지금 배율을 보이고, 누르면 확대, 축소, 실제 크기, 모두 보기, 고른 것에 맞추기가 나온다 |
| 레이어 패널 | 왼쪽. 페이지와 그 안의 것이 나무로 보인다(아래 "레이어와 페이지"). 도구 줄의 단추나 `보기` → `레이어 패널`로 접고 편다 |
| 판 | 페이지와 요소가 그려진다. 고른 것의 상자와 크기 손잡이, 글 상자의 커서와 선택도 여기에 그려진다. 오른쪽 단추로 누르면 메뉴(복사, 붙여넣기, 복제, 지우기)가 뜬다 |
| 속성 패널 | 오른쪽. 맨 위에 맞춤과 간격 단추가 있다. 고른 것이 없으면 안내만 나온다. 버전 기록을 여는 동안은 접힌다 |

엔진이 받아들이지 않은 일(예: 페이지 밖에 도형 놓기)은 화면 아래에 한 줄로 알린다.

## 도구와 단축키

| 도구 | 키 | 만드는 법 |
|---|---|---|
| 고르기 | V | 누르면 고르고, 끌면 옮긴다. 빈 곳을 끌면 영역으로 고른다. ⇧를 누르고 눌러 더하거나 뺀다 |
| 프레임 | F | 페이지 안에서 끌면 프레임, 판의 빈 곳에서 끌면 새 페이지 |
| 사각형, 타원 | R, O | 페이지나 프레임 안에서 끌어 만든다. 한 번 누르기만 하면 100×100이다. ⇧는 정사각형 |
| 선 | L | 끌어서 두 끝을 정한다. ⇧는 15도 단위 |
| 글 | T | 끌면 너비가 정해지고, 누르기만 하면 글이 쓰는 대로 늘어난다. 만들자마자 글을 쓸 수 있다 |
| 그림 | 도구 줄의 `그림` | 파일(PNG, JPEG)을 고른 뒤 판을 누르거나 끌면 그 자리에 놓인다. 20MB, 6,400만 화소까지이고 끝까지 읽히지 않는 파일은 놓지 않는다. 단축키는 없다 |

도구는 한 번 만들면 고르기로 돌아온다. Esc로 도구를 풀 수 있다.

| 키 | 일 |
|---|---|
| Delete, Backspace | 고른 것 지우기(마지막 페이지는 지울 수 없다) |
| ⌘C, ⌘X | 고른 것 복사, 잘라내기 |
| ⌘V, ⇧⌘V | 붙여넣기, 제자리에 붙여넣기 |
| ⌘D | 복제(원본에서 조금 비켜 놓인다. 페이지는 오른쪽에 놓인다) |
| ⇧H, ⇧V | 가로로 뒤집기, 세로로 뒤집기 |
| ⌥A, ⌥H, ⌥D, ⌥W, ⌥V, ⌥S | 왼쪽, 가로 가운데, 오른쪽, 위, 세로 가운데, 아래 맞춤 |
| ⌘A | 같은 부모 안의 것 모두 고르기(고른 것이 없으면 모든 페이지) |
| 방향키, ⇧ 방향키 | 1, 10씩 옮기기 |
| Enter | 고른 글 상자 하나의 글 고치기 |
| Esc | 글 고치기 끝내기 → 도구 풀기 → 고른 것 풀기(한 번에 하나) |
| ⌘Z, ⇧⌘Z | 되돌리기, 다시 하기 |
| ⌘0, ⇧1, ⇧2 | 100%, 모두 보기, 고른 것에 맞추기 |
| ⌘+, ⌘− | 확대, 축소(한 걸음 1.25배) |
| ⌘G, ⇧⌘G | 묶기, 묶음 풀기 |
| ⌘], ⌘[ | 한 칸 앞으로, 한 칸 뒤로 |
| ⌥⌘], ⌥⌘[ | 맨 앞으로, 맨 뒤로 |
| ⇧⌘H, ⇧⌘L | 숨기기·보이기, 잠그기·잠금 풀기 |
| N, ⇧N | 다음 페이지, 앞 페이지로 보기 옮기기 |

글 상자의 글을 고치는 동안에는 글자 키가 모두 글로 들어간다(V, R 같은 도구 키와 페이지 사이를 옮기는 N도 글자다). 묶기, 순서, 숨기기·잠그기, 페이지 더하기는 글을 고치는 동안에는 쓰지 않는다.

## 레이어와 페이지

- 레이어 패널의 맨 위 줄들은 페이지다. 페이지는 PDF의 쪽 차례대로 위에서 아래로 놓이고, 줄 오른쪽에 크기(예: `1920×1080`)가 보인다. 페이지 안에서는 앞에 놓인 것이 위에 온다. 자식이 있는 줄은 앞의 화살표로 접고 편다. 판에서 고르면 그 줄의 위쪽 줄들이 펴지고 그 줄이 칠해진다.
- 줄을 누르면 그것을 고른다. ⌘를 누르고 누르면 더하거나 빼고, ⇧를 누르고 누르면 같은 부모 안에서 앞서 누른 줄까지를 고른다. 부모가 다른 줄은 함께 고르지 않는다. 페이지 줄을 누르면 보기가 그 페이지로 옮겨 간다.
- 줄을 두 번 누르면 이름을 바꾼다. Enter로 정하고 Esc로 그만둔다. 이름이 없는 글 상자는 그 글이, 그 밖은 종류 이름이 보인다.
- 줄에 마우스를 올리면 자물쇠와 눈 단추가 나온다. 잠갔거나 숨긴 줄에는 늘 보인다. 그 줄 하나만 바꾸고 고른 것은 그대로다. 숨긴 것과 그 안의 것은 줄이 흐리게 보인다.
- 줄을 끌어 놓으면 차례나 부모가 바뀐다. 줄 사이에 놓으면 그 자리로, 페이지·프레임·그룹 줄의 가운데에 놓으면 그 안의 맨 앞으로 간다. 고른 줄을 끌면 고른 것이 함께 간다. 다른 부모로 옮겨도 판에서 보이는 자리는 그대로다. 페이지는 페이지끼리만, 페이지가 아닌 것은 페이지 안으로만 옮긴다. 놓을 때 한 번 저장된다(되돌리기 한 번).
- 숨긴 것은 판에 그리지 않고 PDF에도 들어가지 않는다. 잠근 것은 판에서 눌러도 골라지지 않고 끌어 옮길 수 없다. 레이어 패널에서는 고를 수 있고 속성 패널로 값을 바꿀 수 있다.
- 묶기(⌘G)는 같은 부모의 고른 것을 그룹 하나에 넣는다. 그룹의 상자는 늘 그 안의 것을 감싼다. 그룹을 누르면 그룹이 골라지고, 두 번 누르거나 ⌘를 누르고 누르면 그 안의 것이 골라진다. 묶음 풀기(⇧⌘G)는 그 안의 것을 그룹이 있던 자리에 꺼낸다. 그룹 안의 것의 X, Y는 그룹이 든 페이지나 프레임을 기준으로 보인다.
- 레이어 패널 머리의 `+`로 페이지를 더한다. 크기는 A4, US Letter, 1920×1080, iPhone 16(393×852), iPhone 16 Pro Max(440×956), Android(412×917) 가운데 고른다. 새 페이지는 가장 오른쪽 페이지의 오른쪽에 놓이고 PDF의 마지막 쪽이 된다. 페이지 하나를 고르면 속성 패널의 `페이지 크기`에서 크기와 세로·가로를 바꾼다. W, H를 직접 쓰면 `사용자 지정`이 된다. 페이지 이름은 줄을 두 번 눌러 바꾸고, 지우기는 다른 것과 같다(마지막 페이지는 지울 수 없다).
- 페이지 사이는 N(다음), ⇧N(앞)이나 `보기` 메뉴의 `다음 페이지`, `앞 페이지`로 옮겨 간다. 끝에서는 처음으로 돈다.

## 끌어서 고치기

고른 것의 상자에서 어디를 끄는지에 따라 하는 일이 다르다. 끄는 동안은 판에서 미리 보이고, 놓을 때 한 번만 저장된다(되돌리기 한 번). 수정 키는 끄는 도중에 누르거나 떼어도 바로 반영된다.

| 끄는 곳 | 하는 일 | ⇧ | ⌥ |
|---|---|---|---|
| 고른 것의 안 | 옮기기 | 가로나 세로 한 축으로만 | 누른 채 끌기 시작하면 사본을 끈다(원본은 제자리) |
| 가장자리와 모서리의 손잡이 | 크기 바꾸기 | 가로세로 비율 유지 | 가운데를 기준으로 양쪽으로 |
| 모서리 손잡이의 바로 바깥 | 돌리기 | 15도씩 | |
| 선의 끝점 | 끝점 옮기기 | 15도씩 | |

- 돌리기는 상자의 가운데가 기준이다. 여러 개를 골랐으면 묶음의 가운데를 기준으로 함께 돈다. 페이지와 선은 이 방법으로 돌리지 않는다(선은 끝점을 끈다). 모서리 바로 바깥을 끌지 않고 누르기만 하면 그 자리에 있는 것이 골라진다.
- 하나를 고르면 상자와 손잡이가 돈 채로 그려지고, 여러 개를 고르면 축에 나란한 상자 하나가 그려진다.
- ⇧와 ⌥는 함께 쓸 수 있다(비율을 지키며 가운데 기준으로).
- ⌥로 사본을 끌 때 ⌥는 끌기를 시작하는 순간에만 본다. 끄는 도중에 누르거나 떼어도 바뀌지 않는다.

## 맞춰 붙기와 거리 재기

- 옮기거나 크기를 바꾸거나 선의 끝을 끌면, 같은 부모 안의 다른 것(형제)과 둘러싼 페이지·프레임의 왼쪽·가운데·오른쪽, 위·가운데·아래에 붙는다. 그룹 안의 것을 끌면 그 그룹의 다른 자식과 둘러싼 페이지·프레임에 붙는다. 페이지끼리도 붙는다. 붙는 거리는 화면에서 6 화소다. 배율과 상관없이 화면에서 같은 거리에서 붙는다.
- 숨긴 것에는 붙지 않고 잠근 것에는 붙는다. 그룹 안의 것을 끌 때는 그룹이 아니라 그룹이 든 페이지·프레임의 변과 가운데에 붙는다(그룹은 자식을 따라 커지고 줄어드는 상자다).
- 붙은 곳에는 빨간 안내선이 그 선에 놓인 것들을 이어 보인다.
- 옮길 때는 같은 간격에도 붙는다: 줄지어 놓인 것들 사이의 간격과 같아지는 자리, 양옆의 간격이 같아지는 한가운데. 분홍 선과 간격 숫자가 보인다.
- 돌아간 것은 축에 나란한 경계 상자로 본다. 90도의 곱절이 아닌 각으로 돈 것의 크기를 바꿀 때는 붙지 않는다.
- ⌃(Control)를 누르는 동안은 붙지 않는다. 끄는 도중에 누르거나 떼면 바로 반영된다.
- ⇧로 한 축에 묶어 옮기면 그 축으로만 붙는다. ⇧로 비율을 지키며 크기를 바꾸면 더 가까운 변 하나가 붙고 다른 쪽은 비율을 따른다. 선의 끝을 ⇧(15도)로 끌 때는 붙지 않는다.
- 안내선은 끄는 동안에만 보이고 저장된 문서와 PDF에는 들어가지 않는다. 붙어도 놓을 때 한 번만 저장된다.
- 거리 재기: 고른 채 ⌥를 누르고 다른 것 위에 마우스를 올리면 고른 것에서 그것까지의 거리가 빨간 선과 숫자로 보인다. 빈 곳이나 고른 것 위에서는 고른 것이 든 페이지나 프레임까지의 네 거리가 보인다. ⌥를 떼거나 판 밖으로 나가면 사라진다.

## 맞춤과 간격, 뒤집기

- 맞춤(속성 패널 맨 위의 단추 여섯, `개체` 메뉴): 하나만 골랐으면 그것이 든 페이지나 프레임에 맞추고, 여러 개를 골랐으면 고른 것들을 감싼 경계에 맞춘다. 돌아간 것은 축에 나란한 경계 상자로 본다. 페이지 하나만 골랐으면 맞출 곳이 없다.
- 간격 고르게(단추 둘, `개체` 메뉴): 셋 이상을 골랐을 때 가로나 세로로 처음과 끝을 그대로 두고 사이 간격을 같게 한다.
- 뒤집기(⇧H, ⇧V, 속성 패널의 단추, `개체` 메뉴): 여러 개를 골랐으면 묶음의 가운데를 지나는 축을 기준으로 뒤집는다. 페이지는 뒤집지 않는다.

## 복사와 붙여넣기

- ⌘C는 고른 것을 자손과 함께 기억한다. 그림을 칠한 요소도 그대로 붙는다. 다른 캔버스 문서에도 붙일 수 있다. 앱을 끄면 기억한 것은 사라진다.
- 시스템 클립보드에는 고른 것 안의 글 상자의 글이 글자만 들어간다(다른 앱에 붙이면 그 글이 붙는다).
- 붙는 자리:

  | 붙일 때 고른 것 | 붙는 곳 |
  |---|---|
  | 복사한 것이 있던 페이지나 프레임 안의 것(복사한 것 자신 포함) | 같은 곳에 원래 자리에서 조금 비켜서. 거듭 붙이면 그만큼 더 비킨다 |
  | 다른 프레임이나 페이지 | 그 안. 원래 좌표가 그 안에 들면 그대로, 넘치면 가운데 |
  | 없음 | 보이는 영역의 가운데가 든 페이지(없으면 가장 가까운 페이지)에, 보이는 영역의 가운데 쪽 |

- ⇧⌘V(제자리에 붙여넣기)는 판에서 원래 있던 자리에 붙인다.
- 페이지를 복사해 붙이면 있는 페이지들의 오른쪽에 새 페이지로 놓인다.
- 글 상자의 글을 고치는 동안에는 ⌘C, ⌘X, ⌘V가 그 안의 글을 다룬다.

- 두 손가락으로 쓸거나 마우스 휠을 굴리면 판이 움직인다. ⌘를 누르고 쓸면 커서 자리를 기준으로 확대·축소한다. 트랙패드를 벌리거나 오므려도 된다.
- 배율은 2%에서 25600%까지다. 문서에 저장되지 않는다.

## 속성 패널

고른 것의 값이 보이고, 칸에 쓰고 Enter를 누르거나 다른 곳을 누르면 바뀐다. 한 번 바꾸는 것이 되돌리기 한 번이다. 숫자 칸의 앞 글자(X, Y, W, H 등)를 좌우로 끌어도 값이 바뀐다. 끄는 동안은 판에서 미리 보이고, 놓을 때 한 번만 저장된다.

| 구역 | 값 |
|---|---|
| 이름 | 요소의 이름 |
| 맞춤과 간격 | 맞춤 단추 여섯(왼쪽, 가로 가운데, 오른쪽, 위, 세로 가운데, 아래)과 간격 고르게 단추 둘(가로, 세로) |
| 위치와 크기 | X, Y, W, H(페이지의 X, Y는 가운데), 각도(도, 시계 방향이 양수)와 뒤집기 단추 둘. 각도는 고른 것마다 제 가운데를 기준으로 정한다 |
| 모양 | 불투명도(%), 모서리(사각형과 프레임) |
| 페이지 크기(페이지 하나) | A4, US Letter, 1920×1080, iPhone 16, iPhone 16 Pro Max, Android 가운데 고르기와 세로·가로 |
| 칠 | 색(`#RRGGBB`. 앞의 견본 네모를 누르면 색 판이 열린다), 칠 불투명도, `칠 없음`. 글 상자에서는 `글 색` |
| 선 | 색(견본 네모의 색 판도 된다), 굵기, 위치(안쪽(기본값), 가운데, 바깥. 옆의 ⓘ와 아래 한 줄에 설명이 있다), `선 없음` |
| 글(글 상자) | 크기, 굵기(보통 400, 굵게 700), 정렬(왼쪽, 가운데, 오른쪽, 양쪽) |

여러 개를 고르면 값이 모두 같은 칸만 값이 보이고, 다른 칸은 비어 "혼합"이 보인다. 칸에 쓰면 고른 것 모두에 같은 값이 들어간다. 어느 요소에도 쓸 수 없는 값(예: 사각형의 글 크기)은 엔진이 받아들이지 않는다.

## 글 상자 고치기

- 글 상자를 두 번 누르거나, 글 상자 하나를 골라 Enter를 누른다. 글 상자를 새로 만들면 바로 시작된다.
- 한글은 조합하면서 쓴다. 커서, 선택, 조합 중인 글의 밑줄은 판에 그려진다. 두 번 누르면 낱말, 세 번 누르면 줄이 골라진다.
- 고치는 동안의 ⌘C, ⌘X, ⌘V는 글 상자 안의 글만 복사하고 자르고 붙인다. 붙이는 글은 모양 없이 글만 들어간다.
- Esc나 글 상자 밖을 누르면 끝난다. 글이 비어 있으면 그 글 상자는 지워진다.
- 글 일부만 굵게 하는 것 같은 글자별 모양은 없다. 글 상자 전체의 크기, 굵기, 색, 정렬만 속성 패널에서 바꾼다.

## 되돌리기, 버전, 내보내기

- 되돌리기와 다시 하기는 글이 흐르는 문서와 같다. 끌기 한 번(옮기기, 크기, 돌리기, 사본 끌기), 글 한 덩어리 입력, 속성 하나, 맞춤이나 붙여넣기 한 번이 각각 한 단계다.
- 위쪽 줄의 `버전 기록` 단추: 5분 동안 쉬었을 때와 문서를 닫을 때 버전이 자동으로 남고, 이름을 붙여 남길 수도 있다. 버전을 고르면 페이지와 요소의 수, 글 상자의 글이 미리 보이고, 그 버전으로 되돌릴 수 있다. 되돌리기 전 상태는 "되돌리기 전" 버전으로 남는다.
- `PDF로 내보내기`: 모든 페이지를 내보낸다(숨긴 페이지는 들어가지 않고, 보이는 페이지가 없으면 저장할 곳을 묻기 전에 알린다). 페이지마다 쪽 하나이고 쪽 크기는 페이지 크기다. 화면에 보이는 것과 같은 그림으로 나가며, 끌고 있던 것이나 조합 중인 글은 들어가지 않고 저장된 문서가 나간다. 읽지 못하는 그림은 회색 상자로 넣고 내보낸 뒤 알린다. Word 문서, 텍스트 내보내기와 인쇄, 공유는 글이 흐르는 문서에만 있다.

## Figma로 보내기

캔버스 문서를 Figma 데스크톱 앱에서 연 파일로 보낸다. Figma 쪽에는 MIT 라이선스의 플러그인 "Claude Talk to Figma"를 쓴다. 플러그인 파일은 앱에 들어 있다.

처음 한 번은 설정 → `Figma`에서 준비한다.

1. `Figma 데스크톱 앱` 줄이 `설치됨`인지 본다. `없음`이면 `Figma 받기`로 Figma의 내려받기 쪽을 열어 설치한다. 플러그인은 데스크톱 앱에서만 가져올 수 있다.
2. `중계` 줄의 `중계 켜기`를 누른다. 이 맥에서 이미 같은 중계가 3055번 자리에 켜져 있으면 그것을 쓰고, 없으면 Kari가 켠다. Kari가 켠 중계는 127.0.0.1에만 묶고 Kari를 끄면 함께 꺼진다. 이미 켜져 있던 중계를 쓰면 그 중계가 받는 주소와 연결 검사는 그것을 켠 프로그램이 정한다(Kari의 중계 규칙은 적용되지 않는다. [privacy.md](privacy.md#figma로-보내기)).
3. `플러그인` 줄의 `경로 복사`를 누른다. 플러그인 파일을 자료 폴더에 쓰고 그 안의 `manifest.json` 경로를 클립보드에 넣는다.
4. Figma에서 파일을 열고 메뉴의 플러그인 → 개발 → manifest에서 플러그인 가져오기를 누른다. 파일 고르기 창에서 ⇧⌘G를 누르고 복사한 경로를 붙여넣는다. macOS가 Figma에게 다른 앱의 자료에 닿아도 되는지 물으면 허용한다.
5. Figma에서 플러그인을 실행하면 플러그인 창에 채널 ID(영문과 숫자 8자)가 보인다.
6. Kari의 `채널` 칸에 그 ID를 넣고 `연결`을 누른다. Kari가 `ping`으로 그 채널에 플러그인이 있는지 확인하고, 상태가 `연결됨 · 페이지 이름`이 된다. 실패하면 `실패 · 까닭`이 보인다. 마지막으로 연결한 채널은 다음에 칸에 미리 들어 있다.

보내기

1. 캔버스 문서 위쪽 줄의 `⋯` → `Figma로 보내기…`를 누른다.
2. `받을 페이지`에서 연결된 파일의 페이지를 고르거나 `새 페이지`를 골라 이름을 쓴다.
3. `자리 지시`는 비워 두어도 된다. 예: "디자인 페이지의 맨 오른쪽에 절반 크기로".
4. 창에 무엇이 어디로 가는지가 보인다. Figma로는 문서 내용(Kari의 페이지는 프레임으로, 도형, 글, 그림)이 가고, AI로는 크기·개수 요약, Figma 페이지 이름과 지시 글만 간다(문서 본문은 가지 않는다).
5. `보내기`를 누르면 요소를 하나씩 만들며 진행이 보이고, 끝나면 몇 개를 보냈는지와 빠진 것이 한 줄로 보인다.

자리 정하기

- 지시가 비었거나 AI 키가 없으면 AI를 부르지 않는다. 고른 페이지에 이미 있는 것들의 오른쪽으로 200 떨어진 곳(그 맨 위 높이)에 놓는다. 새 페이지면 (0, 0)이다.
- 지시가 있고 키가 있으면 면접과 같은 AI 연결로 자리만 묻는다. Claude 키가 있으면 Claude Haiku, 없으면 OpenAI의 GPT Luna를 낮은 생각 깊이로 쓴다. AI는 `{page, newPage, x, y, scale, frameName}` 하나만 답한다. 모르는 칸이 있거나, 좌표가 -100000~100000을 넘거나, 배율이 0.1~4 밖이거나, 없는 페이지를 가리키면 아무것도 만들지 않고 알린다.
- AI가 정하는 것은 자리, 배율, 페이지, 프레임 이름뿐이다. 무엇을 만들지는 Kari가 문서에서 정해진 규칙으로 바꾼다.

옮기는 것

| Kari | Figma |
|---|---|
| 페이지 | 프레임(Kari의 페이지가 여럿이면 서로 떨어진 거리를 지킨다. 하나면 이름은 프레임 이름이나 문서 이름) |
| 프레임, 구역 | 프레임(안의 것은 그 프레임 안의 자리) |
| 사각형, 타원, 선, 글 상자 | 사각형, 타원, 선, 글 |
| 그림 | 그림을 칠한 사각형(8MB까지) |
| 그룹 | 풀어서 그 안의 것을 바깥 프레임에 놓는다 |

- 칠과 선의 색과 불투명도, 선 굵기, 모서리 반지름, 각도(가운데를 기준으로), 요소의 불투명도, 글의 내용, 크기, 굵기, 정렬, 글꼴 이름이 간다.
- Figma에 그 글꼴(예: Pretendard)이 없으면 글은 Figma의 기본 글꼴(Inter)로 남는다. 그림을 Figma가 받지 않으면(4096 화소 초과 등) 그 사각형은 그림 없이 남는다. 둘 다 끝난 뒤의 한 줄에 개수가 보인다.
- 숨긴 것과 다각형, 별, 벡터, 불리언, 동영상, 표는 보내지 않는다. 뒤집기, 선의 위치(안쪽·바깥), 점선, 효과, 그라디언트도 가지 않는다.
- 한 번에 500개까지 보낸다. 넘으면 보내기 전에 알린다.
- Kari는 Figma에서 만들기, 값 바꾸기, 옮기기, 크기 바꾸기, 페이지 만들기와 읽기 명령만 보낸다. 지우는 명령은 보내지 않는다. 중간에 멈추면 그때까지 만든 것은 Figma에 남는다.

## Figma에서 가져오기

연결된 Figma 파일의 페이지 하나를 새 캔버스 문서로 가져온다. 연결은 위의 "Figma로 보내기"와 같다.

1. 메뉴 막대의 `파일` → `Figma에서 가져오기…`를 누른다. 연결되지 않았으면 창이 알리고 `설정 열기`로 설정의 `Figma` 구역을 연다.
2. `가져올 페이지`에서 페이지를 고른다. Kari가 그 페이지를 읽어 오는 것(페이지, 요소, 그림의 수)과 옮기지 못하는 것을 종류마다 센 수를 먼저 보인다. 이때는 문서를 만들지 않는다.
3. `가져오기`를 누르면 그림을 하나씩 받으며 진행이 보인다. 그동안 `멈추기`를 누르거나 창의 바깥을 누르거나 Esc를 누르면 Figma에 명령을 더 보내지 않고 곧 멈추며, 아무것도 만들지 않는다(이미 넣은 그림도 지운다). 창은 멈춘 뒤에 닫힌다.
4. 끝나면 새 캔버스 문서가 만들어지고, 무엇을 가져왔고 무엇이 빠졌는지가 한 줄로 보인다. `열기`로 그 문서를 연다. 문서 이름은 Figma 페이지 이름이다(제어 문자를 지우고 180자까지 줄이며, 이미 있는 이름이면 번호가 붙는다).

- 가져온 것은 묶음 하나로 들어가 되돌리기 한 번에 빈 페이지 하나로 돌아간다.
- Figma 파일은 읽기만 한다. Kari가 보내는 명령은 페이지 목록, 노드 정보 읽기, 노드를 PNG로 내보내기뿐이다.
- 앱에 든 플러그인은 노드마다 돌린 각도, 크기, 벡터 경로를 함께 알려 준다. 이 기능 전에 가져온 플러그인이면 설정 → `Figma`의 `경로 복사`를 다시 눌러 플러그인 파일을 새로 쓰고 Figma에서 플러그인을 다시 실행한다. 옛 플러그인으로 가져오면 돌린 요소는 돌리지 않은 경계 상자로, 곧은 벡터 선은 옮기지 못한 것으로 온다.

옮기는 것

| Figma | Kari |
|---|---|
| 페이지의 최상위 프레임(컴포넌트, 인스턴스, 구역 포함) | 페이지(Figma의 차례대로, 자리와 크기 그대로. 돌린 프레임은 그 경계 상자) |
| 안쪽 프레임, 컴포넌트, 인스턴스, 구역 | 프레임(인스턴스는 떼어 낸 프레임) |
| 그룹 | 그룹 |
| 사각형, 타원, 선, 글 | 사각형, 타원, 선, 글 상자 |
| 경로가 곧은 선 하나인 벡터 | 선 |
| 그림 칠이 있는 사각형·타원 | Figma가 그린 PNG를 칠한 사각형(그 노드의 선과 둥근 모서리까지 든 그림. 돌린 것은 돌리지 않은 경계 상자에) |

- 단색 칠과 선의 색과 불투명도, 선 굵기와 위치(안쪽·가운데·바깥), 모서리 반지름(모서리마다 다른 것 포함), 자리, 크기, 각도, 뒤집기, 요소의 불투명도, 숨김, 이름, 프레임의 내용 자르기, 글의 내용, 크기, 굵기, 기울임, 가로 정렬, 크기 맞춤 방식이 온다.
- 글꼴은 Pretendard가 된다(앱에 든 글꼴). Pretendard가 아니던 글 상자의 수가 미리 보기와 끝의 한 줄에 보인다.
- 옮기지 못하고 세는 것: 벡터, 불리언, 별·다각형, 마스크, 그라디언트 칠과 그 밖의 칠(칠은 빼고 요소는 온다), 효과(빼고 요소는 온다), 자동 배치(배치 규칙은 빼고 프레임은 온다), 글자별 모양(글 상자 전체의 모양으로 온다), 프레임·글의 그림 칠, 최상위의 프레임이 아닌 요소, 64단보다 깊이 든 요소, 같은 id가 겹친 요소(앞의 것만 온다), 10만 자를 넘어 자른 글, 값이 이상한 요소(수가 아님, 크기 0이나 음수, 절댓값 1,000,000을 넘는 값, 돌리기·뒤집기가 아닌 늘이거나 찌그러뜨린 변환). 제약은 옮기지 않는다.
- 이름과 글의 제어 문자와 글 방향을 바꾸는 문자는 지운다. 범위 밖의 색과 불투명도는 0~1로 자른다.
- 한도: 한 번에 요소 3,000개(읽는 노드 20,000개), 가져올 때의 값 모두 합쳐 4MB까지다. 넘으면 미리 보기에서 알리고 가져오지 않는다. 그림은 200개, 하나에 8MB, 모두 합쳐 128MB까지 받고, Figma가 내보내지 못하거나 그림이 아닌 것은 빈 사각형으로 두고 그 수를 알린다.
- 시간: 페이지 읽기는 120초, 그림 하나는 60초를 기다린다. 진행 알림이 오면 다시 세지만 명령 하나에 10분을 넘지 않는다. 시간을 넘기거나 연결이 끊기면 가져오기를 그만두고 아무것도 만들지 않는다.
- 가져온 요소는 저마다 Figma 노드 id와 가져올 때의 값을 문서 안에 함께 지닌다(다음에 Figma와 다시 맞출 때 쓴다). 값이 60KB를 넘는 요소(아주 긴 글 상자)는 id만 지닌다. 그 요소를 복제하거나 복사해 붙인 것도 같은 값을 지닌다.

## 메뉴 막대

캔버스 문서가 열려 있으면 메뉴가 바뀐다: `Kari`(업데이트 확인…, 설정…과 macOS가 주는 항목), `파일`(새 문서, 가져오기…, Figma에서 가져오기…, 홈으로, PDF로 내보내기, 버전 기록), `편집`(되돌리기, 다시 하기, 잘라내기, 복사, 붙여넣기, 제자리에 붙여넣기, 복제, 지우기, 모두 선택), `보기`(확대, 축소, 실제 크기, 모두 보기, 고른 것에 맞추기, 다음 페이지, 앞 페이지, 레이어 패널, 전체 화면), `개체`(묶기, 묶음 풀기, 앞뒤 순서 넷, 숨기기·보이기, 잠그기·잠금 풀기, 가로·세로로 뒤집기, 맞춤 여섯, 간격 고르게 둘), `도구`(고르기, 프레임, 사각형, 타원, 선, 글, `그림…`). ⌘ 없는 키(V, F, R, O, L, T, N, ⇧N, ⇧1, ⇧2, ⇧H, ⇧V, Delete)와 ⌥ 맞춤 키는 메뉴 막대에 걸지 않았다. 판이 받는다.
