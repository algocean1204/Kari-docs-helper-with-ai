# 캔버스 문서

캔버스 문서는 대지(페이지) 위에 프레임, 사각형, 타원, 선, 글 상자, 그림을 자유롭게 놓는 문서다. 글이 흐르는 문서와 달리 모든 것의 자리와 크기를 정한다. 저장 단추는 없다. 고칠 때마다 저장되고, 화면 위쪽에 "자동 저장됨 · 시각"이 보인다. 글이 흐르는 문서는 [writing.md](writing.md)에 있다.

## 만들고 열기

| 하려는 것 | 하는 법 |
|---|---|
| 만들기 | 홈의 "새 캔버스". 대지 하나(1920×1080)가 있는 "제목 없는 캔버스"가 열린다 |
| 열기 | 홈의 문서 목록에서 누른다. 목록에서 "캔버스"와 "글 문서"는 아이콘과 종류 글로 구분된다 |
| 이름 바꾸기, 복제, 휴지통 | 글이 흐르는 문서와 같다(문서 줄의 더 보기 메뉴, 화면 위쪽의 이름) |

## 화면

| 자리 | 있는 것 |
|---|---|
| 위쪽 줄 | 문서 이름, 저장 상태, 되돌리기, 다시 하기, `PDF로 내보내기`, `⋯` 메뉴(`버전 기록`) |
| 도구 줄 | 고르기, 프레임, 사각형, 타원, 선, 글, 그림. 고른 도구는 바탕이 칠해진다. 오른쪽에 `모두 보기`, `100%`와 지금 배율 |
| 판 | 대지와 노드가 그려진다. 고른 것의 상자와 크기 손잡이, 글 상자의 커서와 선택도 여기에 그려진다. 오른쪽 단추로 누르면 메뉴(복사, 붙여넣기, 복제, 지우기)가 뜬다 |
| 속성 패널 | 오른쪽에 늘 있다. 맨 위에 맞춤과 간격 단추가 있다. 고른 것이 없으면 안내만 나온다 |

엔진이 받아들이지 않은 일(예: 대지 밖에 도형 놓기)은 화면 아래에 한 줄로 알린다.

## 도구와 단축키

| 도구 | 키 | 만드는 법 |
|---|---|---|
| 고르기 | V | 누르면 고르고, 끌면 옮긴다. 빈 곳을 끌면 영역으로 고른다. ⇧를 누르고 눌러 더하거나 뺀다 |
| 프레임 | F | 대지 안에서 끌면 프레임, 판의 빈 곳에서 끌면 새 대지 |
| 사각형, 타원 | R, O | 대지나 프레임 안에서 끌어 만든다. 한 번 누르기만 하면 100×100이다. ⇧는 정사각형 |
| 선 | L | 끌어서 두 끝을 정한다. ⇧는 15도 단위 |
| 글 | T | 끌면 너비가 정해지고, 누르기만 하면 글이 쓰는 대로 늘어난다. 만들자마자 글을 쓸 수 있다 |
| 그림 | 도구 줄의 `그림` | 파일(PNG, JPEG)을 고른 뒤 판을 누르거나 끌면 그 자리에 놓인다. 20MB, 6,400만 화소까지이고 끝까지 읽히지 않는 파일은 놓지 않는다. 단축키는 없다 |

도구는 한 번 만들면 고르기로 돌아온다. Esc로 도구를 풀 수 있다.

| 키 | 일 |
|---|---|
| Delete, Backspace | 고른 것 지우기(마지막 대지는 지울 수 없다) |
| ⌘C, ⌘X | 고른 것 복사, 잘라내기 |
| ⌘V, ⇧⌘V | 붙여넣기, 제자리에 붙여넣기 |
| ⌘D | 복제(원본에서 조금 비켜 놓인다. 대지는 오른쪽에 놓인다) |
| ⇧H, ⇧V | 가로로 뒤집기, 세로로 뒤집기 |
| ⌘A | 같은 부모 안의 것 모두 고르기(고른 것이 없으면 모든 대지) |
| 방향키, ⇧ 방향키 | 1, 10씩 옮기기 |
| Enter | 고른 글 상자 하나의 글 고치기 |
| Esc | 글 고치기 끝내기 → 도구 풀기 → 고른 것 풀기(한 번에 하나) |
| ⌘Z, ⇧⌘Z | 되돌리기, 다시 하기 |
| ⌘0, ⇧1, ⇧2 | 100%, 모두 보기, 고른 것에 맞추기 |
| ⌘+, ⌘− | 확대, 축소(한 걸음 1.25배) |

글 상자의 글을 고치는 동안에는 글자 키가 모두 글로 들어간다(V, R 같은 도구 키도 글자다).

## 끌어서 고치기

고른 것의 상자에서 어디를 끄는지에 따라 하는 일이 다르다. 끄는 동안은 판에서 미리 보이고, 놓을 때 한 번만 저장된다(되돌리기 한 번). 수정 키는 끄는 도중에 누르거나 떼어도 바로 반영된다.

| 끄는 곳 | 하는 일 | ⇧ | ⌥ |
|---|---|---|---|
| 고른 것의 안 | 옮기기 | 가로나 세로 한 축으로만 | 누른 채 끌기 시작하면 사본을 끈다(원본은 제자리) |
| 가장자리와 모서리의 손잡이 | 크기 바꾸기 | 가로세로 비율 유지 | 가운데를 기준으로 양쪽으로 |
| 모서리 손잡이의 바로 바깥 | 돌리기 | 15도씩 | |
| 선의 끝점 | 끝점 옮기기 | 15도씩 | |

- 돌리기는 상자의 가운데가 기준이다. 여러 개를 골랐으면 묶음의 가운데를 기준으로 함께 돈다. 대지와 선은 이 방법으로 돌리지 않는다(선은 끝점을 끈다). 모서리 바로 바깥을 끌지 않고 누르기만 하면 그 자리에 있는 것이 골라진다.
- 하나를 고르면 상자와 손잡이가 돈 채로 그려지고, 여러 개를 고르면 축에 나란한 상자 하나가 그려진다.
- ⇧와 ⌥는 함께 쓸 수 있다(비율을 지키며 가운데 기준으로).
- ⌥로 사본을 끌 때 ⌥는 끌기를 시작하는 순간에만 본다. 끄는 도중에 누르거나 떼어도 바뀌지 않는다.

## 맞춤과 간격, 뒤집기

- 맞춤(속성 패널 맨 위의 단추 여섯, `개체` 메뉴): 하나만 골랐으면 그것이 든 대지나 프레임에 맞추고, 여러 개를 골랐으면 고른 것들을 감싼 경계에 맞춘다. 돌아간 것은 축에 나란한 경계 상자로 본다. 대지 하나만 골랐으면 맞출 곳이 없다.
- 간격 고르게(단추 둘, `개체` 메뉴): 셋 이상을 골랐을 때 가로나 세로로 처음과 끝을 그대로 두고 사이 간격을 같게 한다.
- 뒤집기(⇧H, ⇧V, 속성 패널의 단추, `개체` 메뉴): 여러 개를 골랐으면 묶음의 가운데를 지나는 축을 기준으로 뒤집는다. 대지는 뒤집지 않는다.

## 복사와 붙여넣기

- ⌘C는 고른 것을 자손과 함께 기억한다. 그림을 칠한 노드도 그대로 붙는다. 다른 캔버스 문서에도 붙일 수 있다. 앱을 끄면 기억한 것은 사라진다.
- 시스템 클립보드에는 고른 것 안의 글 상자의 글이 글자만 들어간다(다른 앱에 붙이면 그 글이 붙는다).
- 붙는 자리:

  | 붙일 때 고른 것 | 붙는 곳 |
  |---|---|
  | 복사한 것이 있던 대지나 프레임 안의 것(복사한 것 자신 포함) | 같은 곳에 원래 자리에서 조금 비켜서. 거듭 붙이면 그만큼 더 비킨다 |
  | 다른 프레임이나 대지 | 그 안. 원래 좌표가 그 안에 들면 그대로, 넘치면 가운데 |
  | 없음 | 보이는 영역의 가운데가 든 대지(없으면 가장 가까운 대지)에, 보이는 영역의 가운데 쪽 |

- ⇧⌘V(제자리에 붙여넣기)는 판에서 원래 있던 자리에 붙인다.
- 대지를 복사해 붙이면 있는 대지들의 오른쪽에 새 대지로 놓인다.
- 글 상자의 글을 고치는 동안에는 ⌘C, ⌘X, ⌘V가 그 안의 글을 다룬다.

## 보기

- 두 손가락으로 쓸거나 마우스 휠을 굴리면 판이 움직인다. ⌘를 누르고 쓸면 커서 자리를 기준으로 확대·축소한다. 트랙패드를 벌리거나 오므려도 된다.
- 배율은 2%에서 25600%까지다. 문서에 저장되지 않는다.

## 속성 패널

고른 것의 값이 보이고, 칸에 쓰고 Enter를 누르거나 다른 곳을 누르면 바뀐다. 한 번 바꾸는 것이 되돌리기 한 번이다. 숫자 칸의 앞 글자(X, Y, W, H 등)를 좌우로 끌어도 값이 바뀐다. 끄는 동안은 판에서 미리 보이고, 놓을 때 한 번만 저장된다.

| 구역 | 값 |
|---|---|
| 이름 | 노드의 이름 |
| 맞춤과 간격 | 맞춤 단추 여섯(왼쪽, 가로 가운데, 오른쪽, 위, 세로 가운데, 아래)과 간격 고르게 단추 둘(가로, 세로) |
| 위치와 크기 | X, Y, W, H(대지의 X, Y는 가운데), 각도(도, 시계 방향이 양수)와 뒤집기 단추 둘. 각도는 고른 것마다 제 가운데를 기준으로 정한다 |
| 모양 | 불투명도(%), 모서리(사각형과 프레임) |
| 칠 | 색(`#RRGGBB`), 칠 불투명도, `칠 없음`. 글 상자에서는 `글 색` |
| 선 | 색, 굵기, 위치(안쪽, 가운데, 바깥), `선 없음` |
| 글(글 상자) | 크기, 굵기(보통 400, 굵게 700), 정렬(왼쪽, 가운데, 오른쪽, 양쪽) |

여러 개를 고르면 값이 모두 같은 칸만 값이 보이고, 다른 칸은 비어 "혼합"이 보인다. 칸에 쓰면 고른 것 모두에 같은 값이 들어간다. 어느 노드에도 쓸 수 없는 값(예: 사각형의 글 크기)은 엔진이 받아들이지 않는다.

## 글 상자 고치기

- 글 상자를 두 번 누르거나, 글 상자 하나를 골라 Enter를 누른다. 글 상자를 새로 만들면 바로 시작된다.
- 한글은 조합하면서 쓴다. 커서, 선택, 조합 중인 글의 밑줄은 판에 그려진다. 두 번 누르면 낱말, 세 번 누르면 줄이 골라진다.
- 고치는 동안의 ⌘C, ⌘X, ⌘V는 글 상자 안의 글만 복사하고 자르고 붙인다. 붙이는 글은 모양 없이 글만 들어간다.
- Esc나 글 상자 밖을 누르면 끝난다. 글이 비어 있으면 그 글 상자는 지워진다.
- 글 일부만 굵게 하는 것 같은 글자별 모양은 없다. 글 상자 전체의 크기, 굵기, 색, 정렬만 속성 패널에서 바꾼다.

## 되돌리기, 버전, 내보내기

- 되돌리기와 다시 하기는 글이 흐르는 문서와 같다. 끌기 한 번(옮기기, 크기, 돌리기, 사본 끌기), 글 한 덩어리 입력, 속성 하나, 맞춤이나 붙여넣기 한 번이 각각 한 단계다.
- `⋯` → `버전 기록`: 5분 동안 쉬었을 때와 문서를 닫을 때 버전이 자동으로 남고, 이름을 붙여 남길 수도 있다. 버전을 고르면 대지와 노드의 수, 글 상자의 글이 미리 보이고, 그 버전으로 되돌릴 수 있다. 되돌리기 전 상태는 "되돌리기 전" 버전으로 남는다.
- `PDF로 내보내기`: 모든 대지를 내보낸다. 대지마다 쪽 하나이고 쪽 크기는 대지 크기다. 화면에 보이는 것과 같은 그림으로 나가며, 끌고 있던 것이나 조합 중인 글은 들어가지 않고 저장된 문서가 나간다. 읽지 못하는 그림은 회색 상자로 넣고 내보낸 뒤 알린다. Word 문서, 텍스트 내보내기와 인쇄, 공유는 글이 흐르는 문서에만 있다.

## 메뉴 막대

캔버스 문서가 열려 있으면 메뉴가 바뀐다: `파일`(새 문서, 홈으로, PDF로 내보내기, 버전 기록), `편집`(되돌리기, 다시 하기, 잘라내기, 복사, 붙여넣기, 제자리에 붙여넣기, 복제, 지우기, 모두 선택), `보기`(확대, 축소, 실제 크기, 모두 보기, 고른 것에 맞추기), `개체`(가로·세로로 뒤집기, 맞춤 여섯, 간격 고르게 둘), `도구`. ⌘ 없는 키(V, F, R, O, L, T, ⇧1, ⇧2, ⇧H, ⇧V, Delete)는 메뉴 막대에 걸지 않았다. 판이 받는다.

## 아직 없는 것

레이어 순서와 묶기, 끌 때 다른 것에 맞춰 붙기와 안내선, 거리 재기, 다른 대지로 끌어 옮기기, 다른 앱에서 복사한 글을 글 상자로 붙이기, 돌리는 동안의 각도 표시, 깜박이는 글 커서, 손잡이 위에서 바뀌는 커서 모양.
